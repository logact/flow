# 词汇学习调度算法

> 本文是项目核心算法的权威规范。调度、计分、目标与毕业规则均以本文为准；其他设计文档或现有代码与本文冲突时，应向本文对齐。
>
> 阅读时可以停在任意一层：先理解整体决策，再按需查看状态、公式和参数依据。本文包含待实现的设计；`lib/scheduler.ts`、`lib/tasks.ts`、`lib/targets.ts` 和 `lib/db.ts` 用于核对实现进度，不反向定义算法。文末列出当前主要差异。

## 第一层：30 秒理解算法

算法每次只回答一个问题：**此刻给用户出哪个词、做什么任务？**

若上一项验证已确认需要重学，先完成对应的建立联系任务。其余新任务的决策顺序是：

1. 有某一轴达到综合运用条件的一批词，先做该轴的综合运用任务。
2. 有预计严重遗忘的词，先验证，失败后重新学习。
3. 其余到达复习点且结束短时冷却的词，按优先级竞争。
4. 如果复习价值都不高，引入一个尚未实测的词。
5. 如果现在没有任务可做，返回最近的可练习时间。

一个普通复习候选的优先级由三个因素共同决定：

```text
优先级 = 词的重要性 × 距离个人目标的缺口 × 遗忘紧迫度
```

算法同时区分：

- `P`：产出/拼写轴；
- `R`：接受/认读轴；
- `L_a / R_a`：某一轴的长期记忆和当前可提取度；
- `C`：P/R 共享的词级短时冷却；
- `F_a`：某词在某轴上**已通过的最高任务标准**，范围 `0–100`，只在通过更高标准的独立考核后上升，答错不下降。`verified_a` 单独表示该成绩目前是否通过复核；一次错误会使其待复核。R 轴 60 分的考核是在熟悉主题、其余语言材料已知的连续文本中以 **150 wpm** 阅读，同时理解目标词与整段；该速度是产品选定的锚点，不是研究证明的通用理解门槛。

分数与遗忘分工：`F_a` 回答「通过过哪一级标准」，`verified_a` 回答「这一级当前是否有效」，`L_a / H_time_a` 回答「隔多久需要再测」。遗忘预测只触发复核，不直接扣分。

任务只按四种学习目的分类：**建立联系（ENCODE）、准确提取（RETRIEVE）、流利训练（FLUENCY）、综合运用（INTEGRATE）**。每种任务声明适用轴、分数范围、材料条件和能提供的证据；填空、选义、篇章阅读、写作等是具体交互实现，不作为调度器的固定步骤。R/P 是能力方向，诊断、急救和维护是派发用途，三者分别记录。

## 第二层：完整决策流程

### 1. 导入词汇

根据用户的阅读、写作目标，计算每个词在 P/R 两条轴上的个人终点。

如果用户提供了词汇量估计，还会结合单词难度推断先验掌握概率 `q`，用于选择首次诊断或教学。未经考核的两轴成绩均为 `0`；先验不写入成绩。

### 2. 首次遇到一个词

尚未实测的词不再一律从低水平教学开始，而是按先验掌握概率路由：

```text
q < 0.3        → ENCODE，purpose = introduce
0.3 ≤ q < 0.7  → RETRIEVE，purpose = diagnose
q ≥ 0.7        → RETRIEVE，purpose = verify，不预先展示答案
```

首次真实作答决定被测轴能否通过对应关卡。R 轴诊断测认读与理解，P 轴诊断测回忆与产出；不能把某一轴通过当成两轴都已验证。先验决定是否先教学，不解锁流利或综合任务。

### 3. 已学词进入复习循环

每次调度时，已实测词先经过两个闸门：

```text
长期记忆闸门：R_a ≤ 0.9
词级冷却闸门：C ≤ 0.5
```

只有两个闸门都通过，该词的对应轴才参与优先级竞争。

`C ≤ 0.5` 等价于：距这个词任意方向的最近一次练习，已经完成 7 个其他任务，**或者**已经过去 20 分钟。任一条件先满足，就结束冷却。

### 4. 候选词竞争

通过闸门的候选按下面的逻辑排序：

```text
P(w,a) = 词频权重 × 目标缺口 × 遗忘增益
```

高频、距离目标更远、更加接近遗忘的词优先。

### 5. 作答后更新

作答结果同时更新：

- 本次考核的通过结果、错误类型与速度证据；
- 对应轴的已通过分数 `F_a` 和当前验证状态 `verified_a`；
- 对应轴的记忆半衰期 `H_time_a`；
- 对应轴最近练习时间；
- P/R 共享的词级冷却时间和任务位置。

成功会延长记忆半衰期，失败会缩短半衰期。

## 第三层：状态与公式

### 1. 输入

```text
profile = { reading_wpm, writing_wpm, vocabulary_size, source_id }
W       = 词集合
freq(w) = 词频，或词在导入材料中的出现频率
tick    = 已完成任务总数
now     = 当前时间
```

`freq(w)` 的来源必须随词库记录：通用词频和书内词频表达的意义不同，不应静默混用。

### 2. 个人目标

先把用户目标速度映射到绝对标尺：

```text
readPos  = clamp01((reading_wpm − 150) / (300 − 150))
writePos = clamp01((writing_wpm − 25)  / (60 − 25))
```

目标分与连续阅读/写作考核使用同一条速度标尺：

```text
target_in(w)  = 60 + 40 × readPos
target_out(w) = 60 + 40 × writePos
```

例如阅读目标为 200 wpm，则 `target_in = 73.33…`；以 200 wpm 在有效连续文本中无提示读懂目标词和整段，通过个人目标考核后可直接达到该分数。阅读 150 / 300 wpm 分别对应 60 / 100 分，写作 25 / 60 wpm 同理。存储和比较使用未舍入数值。没有有效连续文本测速，不能通过 60 分及以上的速度关卡。

词频只影响调度优先级与进度聚合，不再抬高目标分。同一速度目标下，高频词更早获得练习机会，但不要求超过用户声明的速度才能达标。目标变更时重算目标分，并按新目标重新检查速度证据。

默认阅读目标为 150 wpm、写作目标为 25 wpm；当前支持的目标范围分别为 150–300 和 25–60 wpm。范围外的目标须先扩展并校准速度标尺，不应通过 `clamp01` 静默变成另一个目标。

关卡通过后直接写入对应分数，不使用分数容差。`score_met_a ⇔ F_a ≥ target_a`；还须通过当前级别的复核和保持力条件才算该轴完成，见第四层第 5 节。

### 3. 导入先验

设用户估计词汇量为 `V`，单词的词频排名为 `rank(w)`：

```text
q(w) = sigmoid((ln(V) − ln(rank(w))) / 0.7)
```

`q` 是“可能掌握”的概率，只用于首次路由：

```text
F_R(w) = 0
F_P(w) = 0
verified_R(w) = verified_P(w) = false
```

若诊断显示用户已经掌握某一级，可直接参加该级的独立考核；通过后才能写入成绩。无需为了取得高分先逐级重复已会的低级任务。

先验和实测状态分开保存：

```text
prior_mastery_q(w)  // 导入时的掌握概率，只影响路由
introduced(w)      // 是否已实际接触或尝试，导入时为 false
has_observation_a  // 该轴是否已有可归属的真实作答记录，导入时为 false
verified_a         // 当前已通过的最高标准是否仍通过最近的合格复核
```

首次教学或真实作答后设置 `introduced = true`。提取、流利训练或综合运用中有可归属的该轴作答时，设置 `has_observation_a = true`，无论通过或失败；教学曝光、先验和跨轴迁移不设置该标记。首次诊断若暴露目标词知识缺口，安排同轴建立联系任务；仅速度不足时安排同级降强度练习，随后独立复核。

### 4. 长期记忆与共享冷却

对轴 `a ∈ {P, R}`：

```text
Δt_a        = now − last_ts_a
last_ts_any = 该词任意方向最近一次真实练习或教学曝光的时刻
Δt_any      = now − last_ts_any
Δtick_any   = tick − last_tick_any
```

长期记忆和可提取度按轴独立：

```text
L_a(w) = 0.5 ^ (Δt_a / H_time_a)
R_a(w) = L_a(w)
```

词级短时冷却由 P/R 共享：

```text
C(w) = min(
  0.5 ^ (Δtick_any / 7),
  0.5 ^ (Δt_any / 20min)
)
```

`C` 只表示最近一次练习带来的短时启动效应，不代表长期记忆，也不参与 `R_a` 的计算。无论刚做的是读还是写，都会重置这个词的共享冷却。

初始 `H_time_a = 1h`。成功后翻倍，失败后减半，但不低于 1 小时。

尚无时间锚的轴没有可用的遗忘预测：首次提取验证只检查词级冷却，不使用成熟闸门或遗忘紧迫度。首次教学或真实作答为实际涉及的轴建立时间锚；跨轴迁移不建立或刷新另一轴的时间锚。

### 5. 抽象任务类型与候选生成

#### 类型、方向与分数范围

下表中的分数均指**本任务目标轴的 `F_a`**，不使用 `min(F_R, F_P)` 替代。区间包含 100 分端点，分数阈值为待校准的初始设置。

| 抽象类型 | 学习目的 | 适用轴 | 分数适用范围 | 派发条件 | 交互示例（不限定实现） |
|---|---|---|---|---|---|
| `ENCODE` 建立联系 | 建立或重建形式、意义、用法之间的联系 | R 或 P | 通常用于 `0 ≤ F_a < 50`；真实验证失败后的重学可覆盖 `0–100` | 首次低先验教学，或已确认需重学；不因低分自动反复教学 | R：释义与语境讲解；P：示范后有支架地拼写、造句 |
| `RETRIEVE` 准确提取 | 不预先展示答案，确认能否独立认出、理解或产出 | R 或 P | 可用于 `0–100`；普通训练主要用于 `F_a < 50` | 已引入词的基础训练；任何分数下的首次诊断、验证或急救检查 | R：语境选义、释义判断；P：由义产形、语境填空、短答 |
| `FLUENCY` 流利训练 | 在正确理解或表达的基础上提高速度 | R 或 P | `50 ≤ F_a ≤ 100` | 有适合该轴的材料、准确率检查与有效测速方式 | R：限时读句、读段并核验理解；P：限时句段产出 |
| `INTEGRATE` 综合运用 | 在连贯语境中理解或运用多个知识点 | R 或 P | 每个被考查词在本任务轴上 `75 ≤ F_a ≤ 100` | 该轴尚未完成综合验证；具备连贯材料和可检查的理解/产出要求 | R：含多个目标词的篇章理解；P：使用多个目标词完成表达 |

上表是学习目的。用户实际做的动作还必须明确区分：**看词/看示范**只提供教学材料；**识别/回忆**要求先遮住答案再独立作答；**连续读写**要求在有意义的材料中计时并核验理解或表达。看过、照抄、点完页面都不构成关卡通过。

#### 分段考核与动作

`F_a` 记录已通过标准。普通晋级取严格高于当前分的下一个边界，个人目标较低时以个人目标为最后一关：

```text
boundaries = [20, 35, 50, 60, 75, 90, 100]
若 F_a = 0 且尚无已通过标准：checkpoint_a = 20
若 0 < F_a < target_a 且 verified_a：checkpoint_a = min(nextBoundary(F_a), target_a)
若 0 < F_a < target_a 且 ¬verified_a：checkpoint_a = F_a，先复核当前已通过标准
若 F_a ≥ target_a 且 ¬verified_a：checkpoint_a = F_a，只复核，不再晋级
首次诊断可按高先验选择更高关卡挑战；RETRIEVE 最多认证 50，60 及以上须使用合格 FLUENCY 考核
```

| 当前分数 | R 轴合格晋级任务 | P 轴合格晋级任务 | 通过后分数 |
|---|---|---|---|
| `0–19` | 可先看词与语境；遮住答案后，在两个不同语境独立识别形式与含义 | 可先看写法；遮住答案后，在两个不同提示中独立写出词形 | `20` |
| `20–34` | 在句中独立判断目标词含义，排除合理干扰项 | 由意思回忆完整词形，不提供首字母或字母槽位 | `35` |
| `35–49` | 在两个不同句子中独立解释目标词的用法 | 在两个不同语境中独立写出并正确使用目标词 | `50` |
| `50–59` | 熟悉主题、其余语言材料已知的连续文本达到 **150 wpm**，目标词和整段理解均通过 | 连续表达达到暂定 **25 wpm**，目标词用法和整段表达均通过 | `60` |
| `60–74` | 同样的双重理解检查，连续阅读达到 **206.25 wpm** | 连续表达达到 **38.125 wpm**，检查词义与整段表达 | `75` |
| `75–89` | 换新语境，连续阅读达到 **262.5 wpm**，独立理解目标词和整段 | 换新情景，连续表达达到 **51.25 wpm**，正确使用目标词 | `90` |
| `90–99` | 连续阅读达到 **300 wpm**，仍通过目标词和整段理解 | 连续表达达到 **60 wpm**，仍正确使用目标词 | `100` |

个人目标落在两个边界之间时，以该目标分对应的精确 wpm 考核，通过后直接写入目标分。例如目标 200 wpm 对应 `73.33…`，从 60–74 分段考核该目标，通过后为 `73.33…`，无需再考 206.25 wpm。`F_a = 0` 且尚无已通过标准时直接考第一关 20；失败后仍为 0，完成教学或补练后再考。高先验或已有可归属证据可直接挑战较高关卡；只有相同轴的合格考核才能记分。低分选择题的两个语境及干扰项是降低猜中概率的初始要求，具体数量待校准。

`RETRIEVE` 的宽范围用于复核与补练，不表示高分词应持续做低难度题。`INTEGRATE(P)` 只要求所考查词的 P 轴已达到 75 且当前有效，`INTEGRATE(R)` 同理；仅当任务明确同时考查双轴时，才分别检查双轴门槛并分别产生证据。

个人目标优先于继续升级任务：分数、当前验证、速度和保持力都已达标的轴退出训练，不必继续升到 75 再做综合运用。综合运用不是本版本的毕业必经步骤。

#### 任务定义与实例

任务库中的每个定义都要声明：

```text
TaskDefinition = {
  id,
  type: ENCODE | RETRIEVE | FLUENCY | INTEGRATE,
  supported_axes: { R, P } 的非空子集,
  score_range_by_axis,           // 与上表相容，允许某个实现使用更窄范围
  action: view | recognize | recall | contextualize | continuous_read | continuous_write,
  checkpoint_range,              // 此实现可认证的分数范围；教学与普通补练为空
  supported_purposes,
  scope: single | multiple,      // 单词或多词；综合运用为 multiple
  prerequisites,                // 材料、题目生成、理解检查等前提
  evidence: {
    accuracy_check,              // 包含目标词归属、整段理解/表达等
    speed_mode: none | latency_proxy | reading_wpm | writing_wpm,
    attribution: per_word | overall
  },
  renderer                      // 具体交互实现
}

TaskInstance = {
  definition_id, type, checkpoint, // 本次预先声明的关卡；教学和补练为 null
  axis,                         // 本次明确考查的 R 或 P
  purpose: introduce | diagnose | verify | review | recover | relearn | maintain,
  word_ids,
  payload                       // 材料、题目、预算、通过标准与速度要求
}
```

跨轴组合任务由分别声明轴的子任务组成，不能用一次总体通过更新两轴。`type` 决定练什么，`purpose` 解释为什么此刻派发，`renderer` 决定用户如何操作。分线标签可作为教学元数据保留，不参与硬编码题型优先级。

用途与类型的组合也有约束：`introduce / relearn` 使用 ENCODE；`diagnose / verify / recover` 使用 RETRIEVE；`review / maintain` 可使用 RETRIEVE 或 FLUENCY；综合运用批次使用 INTEGRATE、`purpose = review`。用途不会绕过类型的分数与材料要求。

#### 普通候选生成

```text
candidates(w,a) = {
  d ∈ task_library :
  a ∈ d.supported_axes
  且 F_a ∈ d.score_range_by_axis[a]
  且 d 支持本次 purpose
  且 d.prerequisites(w,a) 成立
  且 d.type ∈ { RETRIEVE, FLUENCY }
  且 ¬axis_done_a
}
```

候选为 `(w, a, definition_id)`。建立联系由首次教学或已确认重学触发；综合运用由多词资格与材料共同生成，单独走批次分支。`F_a < 50` 时，R/P 两轴均必须有准确提取任务可派，不再依靠 P→R 迁移作为低分 R 轴的唯一训练入口。

同一 `(w,a)` 的候选共享需求优先级。选择具体实现时，先补齐缺少的证据（尤其真实速度），再按主训练类型选择：低于 50 优先准确提取，达到 50 优先流利训练；材料不足时可回退到同轴提取，但不冒充已完成速度验证。同等条件优先选择近期较少使用的实现，最终按稳定的定义 ID 打破平局。

一个篇章阅读实现可以承载 R 轴流利训练，也可以承载 R 轴综合运用；任务类型由本次学习目的、词集合与证据要求确定，不能仅凭“阅读页面”或材料来源决定。

#### 分数与方向示例

除最后一行外，下表假设对应轴尚未完成个人目标，普通复习已通过时间闸门，且材料可用。

| 状态 | 可选择的训练 |
|---|---|
| `F_R = 20, F_P = 75` | R 做通向 35 的认读考核；P 可做流利训练，若 P 轴当前有效且材料齐备，也可做综合运用 |
| `F_R = 75, F_P = 20` | R 当前有效时可做流利训练或同轴综合运用；P 做通向 35 的产出考核 |
| 某轴通过 50 分关卡 | 该轴解锁连续材料的速度考核，不要求另一轴同时到 50 |
| 某轴到 `75` 且 `verified_a = true` | 该轴新增综合运用资格；仍需检查批次和材料，不自动毕业 |
| R 轴目标 200 wpm，已在该目标下通过双重理解检查并取得 `F_R = 73.33…`，`verified_R = true`，`H_time_R ≥ 30 天` | R 轴已完成，不必继续到 75；P 轴按自身状态继续训练 |

### 6. 分数与验证生命周期

#### 教学、先验与知识迁移

首次展示词义、观看示范、照抄或重学只改变教学状态与冷却锚点，不改变 `F_a`。导入先验 `q` 只决定首次路由；P 轴通过可以提示系统优先安排 R 轴诊断，但不能替 R 轴直接加分。重学不清空已经通过的最高关卡，重学轴的 `verified_a` 与速度认证置为待复核。

#### 每次考核的通过条件

```text
qualified_pass(w,a,k) =
  本次是轴 a、关卡 k 的独立作答
  且未在作答前展示答案或给予会泄露答案的提示
  且通过该关卡规定的全部子项
  且每个计分目标词都有可归属的正确证据
  且 k ≥ 60 时：有合格连续材料、有效实测 wpm ≥ speed_at(a,k)
                 并通过整段理解/表达检查
```

读轴的 `speed_at(R,k) = 150 + (k − 60) × 150 / 40`；写轴的 `speed_at(P,k) = 25 + (k − 60) × 35 / 40`，仅对 `60 ≤ k ≤ 100` 有意义。150 wpm 是整段平均速度，不能换算成每个词的固定 400 ms 反应时限。写作 25–60 wpm 标尺暂沿用产品设定，待独立校准。

```text
若 qualified_pass(w,a,k)：
  F_a ← max(F_a, k)                 // 晋级一次写入下一边界或个人目标
  若 k ≥ F_a 的旧值：verified_a ← true
  若 k ≥ 60 且 k ≥ F_a 的旧值 且本次有效连续测速：speed_verified_a ← true
  H_time_a ← H_time_a × 2
否则若有独立作答且失败：
  F_a 不变
  verified_a ← false
  speed_verified_a ← false
  H_time_a ← max(H_time_a / 2, 1h)
  记录错误类型并安排本轴补练或复核
否则：                              // 观看、照抄、教学和无效测速
  F_a、verified_a、speed_verified_a 均不变
```

判定 `k ≥ F_a 的旧值` 必须使用更新前的成绩；低于当前最高标准的简单任务即使做对，也不恢复当前级别的认证。关卡 `k` 只能由任务定义事先声明并与对应的动作、材料及测速条件匹配，不能根据作答结果临时抬高。高先验直接挑战高关卡时，成功可跳过中间关卡；失败保持原分数。提示后再做对仅用于学习，不覆盖首次独立作答结果。

失败按原因处理：目标词识别或使用错误，安排同轴提取补练；目标词正确但整段理解/表达失败或速度不足，安排同级、较低强度的连续材料重新考核。整段结果不能自动归属给其中每个词。只有总体通过/失败、缺少逐词证据的综合任务可以更新 `integrated_a`，不能改变任一词的 `F_a`。已通过的 60 分表示历史上通过了 150 wpm 标准；若 `verified_R = false`，界面须显示“60 分·待复核”，不得宣称目前仍已认证该速度。

### 7. 普通候选的优先级

```text
w_freq(w) = 1 + ln(1 + freq(w))

score_met_a = F_a ≥ target_a
axis_done_a = score_met_a 且 verified_a 且 speed_verified_a 且 H_time_a ≥ 30 天

gap_a(w) = (target_a − F_a) / target_a              // 尚未通过个人目标关卡
         = 0.05                                    // 分数已达标，但 axis_done_a 为 false
         = 0                                       // axis_done_a 为 true

urgency_a(w) = max(0, (0.9 − L_a) / 0.9)²

P(w,a) = w_freq(w) × gap_a(w) × (1 + 9 × urgency_a(w))
```

`urgency` 使用平方，使刚到复习点的词只得到小幅增益，而越接近遗忘的词增长越快。

`verified_a` 与 `speed_verified_a` 见第四层第 5 节。历史成绩够、当前待复核的轴仍以维护缺口留队；优先安排同级考核，而不是继续升级或因缺口归零提前毕业。

## 第四层：调度器的精确判定

设候选范围 `S` 为激活目标内的词（strict 模式），或全词库（默认模式）。每次调度按下面顺序短路返回。

进入以下新任务分支前，若有上次验证留下的 `pending_relearn(w,a)`，先返回 `ENCODE(w,a,purpose=relearn)`；完成后清除此标记，再恢复普通调度。这是已开始的验证流程的后续步骤，不参与综合运用或普通复习竞争。

### 1. 综合运用批次

```text
对 a ∈ {R, P}：
  pool_a = { w ∈ S : ¬graduated ∧ ¬axis_done_a ∧ ¬integrated_a ∧ F_a ≥ 75 ∧ verified_a }

若某个 INTEGRATE 定义能从 pool_a 生成满足材料要求的批次：
→ 返回 INTEGRATE(axis=a, purpose=review, word_ids=batch)
```

默认批次为 5 个词，可由任务定义明确配置；词数不是任务类型的语义。优先选词频权重总和最高的可用批次，同分按稳定 ID 排序。某轴分数达标不替另一轴满足门槛；没有可用综合材料时继续后续分支，不因凑够词数而阻塞整个队列。

### 2. 急救与普通复习

检查已引入、未毕业词的未完成轴。急救只针对已有该轴真实作答和时间锚的候选，避免把未知状态当成遗忘。

```text
若 has_observation_a 且存在该轴时间锚 且 L_a(w) < 0.2
→ 将 (w,a) 加入急救集 D，该轴不参与普通竞争
→ F_a 保持；verified_a = false，speed_verified_a = false，要求复核当前最高标准
```

急救任务先做不展示答案的同轴提取验证：

```text
若 D 非空
→ (w*,a*) = argmin L_a(w)
→ RETRIEVE(w*,a*,purpose=recover)
→ 当前最高标准低于 60 且完成同级独立考核：保持 F_a，恢复 verified_a，更新 H_time_a
→ 当前最高标准至少 60 且提取正确：仅确认词义，继续安排同级 FLUENCY 速度复核；在该复核通过后才恢复 verified_a 与 speed_verified_a
→ 目标词独立提取失败或需提示：保留 F_a、撤销当前验证，设置 pending_relearn(w*,a*)
→ 完成 ENCODE 后保持历史最高分，重新参加同级独立复核
```

低 `L_a` 是模型预测，不能独自证明已经忘记，更不能清空已通过的成绩；它只使当前认证过期并触发复核。真实目标词失败只触发同轴补练或重学；速度不足而词义正确时，调低同级任务强度再考，不强制重学。需要重学的状态须显式记录。

其余词对每个候选 `(a, definition_id)` 检查双闸门：

```text
R_a(w) ≤ 0.9  // 该轴长期记忆到达复习点
C(w)   ≤ 0.5  // 7 个任务或 20 分钟，任一条件先满足
```

两者都满足且 `P(w,a) > 0` 时进入复习池。没有时间锚的轴按第三层第 4 节处理：结束词级冷却后可做首次提取验证，紧迫度取 0。普通训练的 `purpose = review`；分数已达标但证据或保持力未齐时取 `maintain`；尚无该轴真实作答时取 `verify`。

```text
若 max P ≥ 1.0
→ 先选 argmax P 对应的 (w*, a*)，再选该轴的任务定义
```

选具体实现和材料失败回退遵循第三层第 5 节的证据优先规则：

```text
当前级别待复核且 F_a ≥ 50 → 优先可有效测速的同轴 FLUENCY，考当前级别
F_a < 50                 → RETRIEVE
F_a ≥ 50 且未达目标       → 优先 FLUENCY，考下一关或个人目标
当前实现无法生成材料      → 换同轴同类型实现；仍不可用时回退同轴 RETRIEVE
```

首次未实测轴的 `verify` 使用 RETRIEVE，确认后再进入普通流利训练。不能因 R 轴阅读材料不足而自动切换成 P 轴填空；不同方向重新生成候选、重新比较优先级。回退任务没有实际速度证据时，记录缺口仍在，不视为完成速度验证。

### 3. 引入尚未实测的词

当复习池为空或 `max P < 1.0`：

```text
w_new = argmax freq(w)
        over { w ∈ S : introduced(w) = false }

若存在 w_new：
  选择目标缺口最大的轴 a（同分按固定 R、P 顺序）
  q < 0.3        → ENCODE(w_new,a,purpose=introduce)
  0.3 ≤ q < 0.7  → RETRIEVE(w_new,a,purpose=diagnose)
  q ≥ 0.7        → RETRIEVE(w_new,a,purpose=verify)

若不存在 w_new，但复习池非空：
  → 返回复习池中的 argmax P
```

`NEW_WORD_BYPASS = 1.0` 是经验切换线：当最强复习候选也只是低需求维护时，优先获取一个尚未实测词的信息，或直接教学。

### 4. 当前无任务

```text
若前面都未返回
→ EMPTY
```

等待时间只在当前候选范围内、有可用任务实现且尚未完成的轴上计算：

```text
wait = min over (w,a) {
  t ≥ now : (该轴尚无时间锚 或 R_a(w,t) ≤ 0.9) 且 C(w,t) ≤ 0.5
} − now
```

等待期间全局 `tick` 不变，因此按自然时间计算共享冷却。没有任何未完成轴时，返回完成原因与 `wait = null`。

`EMPTY` 是调度状态，不是任务类型。若仍有未完成轴但所有合格实现都缺材料，返回缺材料原因及涉及的轴，等待时间为 `null`；不要把材料缺口伪装成等待冷却即可恢复。

### 5. 作答后的状态回写

单词任务开始时，先记录目标轴、动作、预先声明的关卡 `k`、目标词和通过标准；提交后用第三层第 6 节的 `qualified_pass` 判定：

```text
若 qualified_pass(w,a,k)：
  F_a = max(F_a, k)
  若 k ≥ 更新前 F_a：verified_a = true
  若 k ≥ 60 且 k ≥ 更新前 F_a 且连续测速有效：speed_verified_a = true
  H_time_a = 2 × H_time_a
否则若有独立作答且未通过：
  F_a 不变
  verified_a = false
  speed_verified_a = false
  H_time_a = max(H_time_a / 2, 1h)

last_ts_a     = now
last_ts_any   = now
last_tick_any = tick + 1
tick          = tick + 1
```

教学曝光没有对应轴的计分作答时，只更新时间锚和共享冷却，不凭展示结果更新 `F_a` 或 `H_time_a`。一次多词任务统一使用任务开始时的 `tick + 1` 回写各词，再将全局 `tick` 增加一次；只有可归属到某词、某轴的合格结果才能晋级该词。事件须保存 `{type, action, definition_id, purpose, axis, word_ids, checkpoint, independent, pass, failure_kind, speed_mode, speed_wpm, comprehension_result, attribution, ts}`，缺失测速记为 `null`，不可沿用旧速度。

知识迁移只改变路由线索，不改变成绩或另一轴时间锚：

```text
P 轴通过 → 可优先生成 R 轴诊断候选；F_R 不变
预算内合格通过 → 对应轴游标 × 1.05，封顶个人目标速度
速度不足或理解失败 → 对应轴游标 × 0.9，不低于材料可用下限
```

按方向独立检查完成条件：

```text
score_met_a = F_a ≥ target_a
verified_a = 最近一次对当前最高标准的独立复核通过，且此后没有该轴失败或急救过期
speed_verified_a = 当前已验证的最高标准具有对应模态的有效连续测速
                   且该速度 ≥ goal_speed_a
                   且整体与目标词的归属检查均通过
axis_done_a = score_met_a 且 verified_a 且 speed_verified_a 且 H_time_a ≥ 30 天

GRADUATED ⇔ axis_done_P 且 axis_done_R
```

一次失败保留 `F_a`，但将该轴显示为“待复核”，暂停该轴完成与毕业判定；完成同级无提示考核后恢复。复核低于历史最高标准的容易任务，不能恢复 `verified_a`。目标速度提高时重新计算 `target_a`；旧成绩保留，但需按新目标检查是否已有合格速度证据。P 轴速度只能来自 `writing_wpm`，R 轴只能来自 `reading_wpm`。单题响应时间、教学展示、跨轴迁移及只有总体结果的综合任务不能提供速度认证。缺少合格材料时该轴保持待验证，不能自动毕业。

优先级、目标达成度和毕业判定统一使用上述谓词：目标达成度统计双轴 `score_met ∧ verified ∧ speed_verified` 的词，毕业另需双轴保持力达标。综合运用门槛 75 独立于个人目标；较低速度目标可以在 75 分前完成，`integrated_a` 不是本版本的毕业前提。

## 参数为什么这样取

### 分段边界与复核

`[20, 35, 50, 60, 75, 90, 100]` 是产品初始关卡，不是 Paul Nation 研究直接给出的分界。低于 60 的关卡要求逐步撤掉提示、增加语境并独立提取；60 及以上以有效连续读写速度和内容检查为考核条件。通过即写入边界或个人目标分；一次失败保留成绩、撤销当前验证。应通过实际数据校准每段任务的误猜率、通过后的跨语境表现、复核失败率与用户是否感到关卡跳跃过大。

### 冷却：7 个任务或 20 分钟

`7` 是控制重复频率和短时启动效应的经验参数，不直接来源于“工作记忆 7±2”。经典容量实验不能推出“完成 7 个任务后短时记忆被清空”。

这里的准确含义是：经过 7 个干扰任务或 20 分钟后，允许同一个词重新参与调度。后续应比较不同参数下的再次作答正确率、重复感、跳过率和退出率。

### 遗忘增益：9

当 `L = 0.2` 时：

```text
urgency ≈ ((0.9 − 0.2) / 0.9)² ≈ 0.60
```

增益为 `9` 时，濒死词的倍率约为：

```text
1 + 9 × 0.60 ≈ 6.4
```

它能让差距不大的濒死词插队，但不会完全压过词频和目标缺口。如果增益过大，队列会退化成单纯按遗忘程度排序，新词很难进入；`9` 让三个因素大致处于同一影响量级。

### 尚待实验校准的参数

```text
先验曲线宽度                  0.7
分数初值                      双轴 0；先验只影响首次路由
首次路由边界                  0.3 / 0.7
任务冷却半衰点                7 个任务
时间冷却半衰点                20 分钟
最快复习点                    R = 0.9
急救线                        已实测轴 L_a = 0.2
流利训练解锁线                对应轴 F_a = 50
综合运用门槛                  对应轴 F_a ≥ 75 且 verified_a，默认 5 个词
晋级关卡边界                  20 / 35 / 50 / 60 / 75 / 90 / 100
读轴 60 分考核                 150 wpm，目标词与整段理解通过
写轴 60 分考核                 暂定 25 wpm，目标词与整段表达通过
新词切换线                    P = 1.0
毕业稳定性                    双轴 H_time ≥ 30 天
```

## 一页公式摘要

```text
已有时间锚的普通复习 ⇔ R_a ≤ 0.9 且 C ≤ 0.5
无时间锚的首次验证只检查 C ≤ 0.5，紧迫度取 0

R_a = L_a = 0.5 ^ (Δt_a / H_time_a)

C = min(
  0.5 ^ (Δtick_any / 7),
  0.5 ^ (Δt_any / 20min)
)

task_type ∈ { ENCODE, RETRIEVE, FLUENCY, INTEGRATE }
task_axis ∈ { R, P }
候选 = (知识点, 轴, 任务定义)
RETRIEVE：0–100，普通训练主要用于 <50；诊断/验证可覆盖全段
FLUENCY：对应轴 ≥50
INTEGRATE：每个目标词的对应轴 ≥75 且 verified_a，另检查批次材料
ENCODE：首次教学或已确认重学，不由分数单独触发

F_a = 0 时先考 20；已有成绩但待复核时先考 F_a
其余晋级：checkpoint_a = min(nextBoundary(F_a), target_a)
qualified_pass(w,a,k) 且 k ≥ 更新前 F_a ⇒ F_a ← max(F_a,k)，verified_a ← true
失败 ⇒ F_a 不变，verified_a ← false，speed_verified_a ← false
观看 / 照抄 ⇒ F_a 不变
target_a = 60 + 40 × goal_speed_position_a
score_met_a ⇔ F_a ≥ target_a
axis_done_a ⇔ score_met_a 且 verified_a 且 speed_verified_a 且 H_time_a ≥ 30 天

P(w,a) =
  (1 + ln(1 + freq))
  × gap_a
  × (1 + 9 × max(0, (0.9 − L_a) / 0.9)²)
```

最终短路顺序：

```text
完成已确认需重学的 ENCODE（若有）
→ INTEGRATE 批次
→ RETRIEVE 急救验证
→ 普通复习竞争
→ 新词 ENCODE / RETRIEVE
→ 低价值复习兜底
→ EMPTY
```

## 实现对齐说明

本次修订更新算法规范，代码与任务页面原型尚未同步。实现时须同时替换旧计分、先验播种、跨轴托底、复核、目标和毕业判定，不能只改一处公式。

| 范围 | 当前实现的主要差异 | 应对齐的规范 |
|---|---|---|
| `lib/tasks.ts`、`lib/scheduler.ts` | 按步骤和页面名称枚举任务，缺少低分 R 轴提取；同分依赖固定题型顺序 | 四种抽象类型；按轴、分数、材料和证据生成候选，题型作为实现注册 |
| `lib/scheduler.ts`、`lib/config.ts` | 旧 EWMA 仍乘 `max(L_a, SCORE_R_FLOOR)`；综合通过直接托底 80 | 合格关卡通过才晋级；失败保分并撤销验证；综合标记与词级晋级分开 |
| `lib/targets.ts`、`lib/config.ts` | 目标仍为 `80 + 15 × position` 并乘词频因子 | 与速度关卡共用 `60 + 40 × position`；重算已有目标分 |
| 优先级、达成度、毕业判定 | 直接比较 `F ≥ target`，缺少独立速度验证 | 统一使用历史成绩、当前验证、真实速度证据与 `axis_done`；维护缺口不能提前归零 |
| `lib/db.ts`、`lib/config.ts` | `R_a = C × L_a`，干扰通道半衰期为 4 个任务 | `R_a = L_a`，共享冷却独立，半衰点为 7 个任务或 20 分钟 |
| 导入与首次路由 | 尚无本文完整的先验及诊断状态 | 双轴成绩从 0 起；区分词级 `introduced` 与轴级 `has_observation_a`；按 `q` 路由 |
| 综合与急救 | 综合只有词级标记且要求双轴 75；低 `L_P` 直接重编码双轴 | 按被考查轴检查综合资格和 `integrated_a`；各轴先验证再同轴重学 |
| 历史记录 | 事件中速度、准确率证据不总齐全 | 记录抽象类型、实现、用途、证据归属与缺失值，禁止自动补造证据 |

旧 `F` 是含折损的平滑估计，不是已通过关卡。迁移时，有完整且可归属事件的轴可按新关卡条件重放，只确认实际通过的最高标准；证据不足时将旧值保留为 `legacy_score` 供展示和诊断，新的 `F_a` 从已证实关卡或 0 开始，`verified_a = false`。不能凭旧分数、先验或迁移记录生成速度认证和毕业状态。

### 旧题型到抽象任务的迁移映射

下表只用于定位现有代码和交互资产。旧标识不再作为算法的任务分类，也不参与题型排序。

| 旧代码标识 | 新抽象类型与轴 | 可复用的实现 |
|---|---|---|
| `STEP12` | `ENCODE(R)` / `ENCODE(P)` | 讲解、示范、有支架形式练习；分别记录涉及的轴 |
| `STEP3` | `RETRIEVE(P)` | 语境填空、由义产形；诊断、验证、复习、急救通过 purpose 区分 |
| 尚无旧标识 | `RETRIEVE(R)` | 语境选义、释义判断等独立认读验证，补齐低分 R 轴入口 |
| `STEP4` | `FLUENCY(P)` | 限时产出与写作测速 |
| `STEP4R` | `FLUENCY(R)` | 限时阅读与理解检查 |
| `MFI` | `FLUENCY(R)`，或满足综合资格时的 `INTEGRATE(R)` | 篇章选材与理解题；按目的、目标词集合及证据归属选择类型 |
| `PART_B` | `INTEGRATE(P)` | 多词连贯表达；不再要求未被考查的 R 轴先到 75 |
| `EMPTY` | 调度状态 | 无可用任务的原因与等待信息 |

旧整合标记只能迁移到实际考查过的轴；缺少方向或证据的历史记录保留待验证，不能自动生成双轴综合或速度认证。
