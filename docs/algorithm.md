# 词汇学习调度算法

> 本文是项目核心算法的权威规范。任务、调度、计分、目标和材料准备均以本文为准。本文描述已确认的产品规则，不表示业务代码已经完成实现对齐。
>
> 本次修订：按当前分数唯一确定任务档位；取消先验、首次诊断、综合运用及毕业机制；提取任务按结果设置档位分数，流利任务按有效实测表现直接计分。

## 第一层：整体决策

每次调度分两步：

1. 根据目标范围、词频、目标缺口、遗忘紧迫度和冷却，选择词 `w` 与轴 `a`。
2. 只根据该轴当前分数 `F_a` 确定任务类型与档位，再取得相应材料。

同一轴、同一分数对应同一任务档位。遗忘预测、急救用途、材料不足或旧验证状态不能改变档位。R/P 是能力方向，不互相代替，也不互相加分。

- `R`：理解方向。
- `P`：产出方向。
- `F_a`：当前训练分数，范围 `0–100`，可以升降；不再表示历史最高成绩。
- `L_a / R_a`：该轴的长期记忆预测与当前可提取度。
- `C`：两轴共享的词级短时冷却。
- `target_a`：用户设置的该轴分数目标。

决策顺序：急救集 → 普通复习竞争 → 引入新词 → 低优先级普通复习兜底 → 当前无任务。

取消 `INTEGRATE` 及其批次优先分支，取消先验 `q` 和首次诊断分支。旧 `verified_a`、`speed_verified_a`、`integrated_a`、`axis_done_a`、`graduated` 不参与本版派发、计分或目标判断。失败后的讲解和重学属于当前练习的反馈环节，不生成独立的计分任务，不使用 `pending_relearn` 抢占调度。

## 第二层：任务与分数

### 1. 分数唯一决定任务

下表的分数只指当前目标轴，不能用 `min(F_R,F_P)` 替代。

| 当前轴分数 | 类型与档位 | R：理解 | P：产出 |
|---|---|---|---|
| `F = 0` | ENCODE | 学习词义、例句 | 学习词义、形式、例句 |
| `0 < F < 20` | RETRIEVE / choice | 看原词选择正确意思 | 看意思选择正确原词 |
| `20 ≤ F < 40` | RETRIEVE / cued | 在提示下写出意思 | 在字母等提示下写出原词 |
| `40 ≤ F < 60` | RETRIEVE / free | 看原词直接给出意思 | 看意思直接写出原词 |
| `60 ≤ F ≤ 100` | FLUENCY | 连续阅读理解与速度 | 连贯表达质量与速度 |

P 的无提示提取仍提供意思或表达意图，但不提供选项、答案字母等线索。有提示任务的支架是该档正式要求，不应因使用规定提示而判无效。

### 2. ENCODE 与 RETRIEVE 计分

按结果直接设置分数，不采用固定小额加减，也不以个人目标截断本次表现分。

| 当前任务 | 成功后的分数 | 失败后的分数 |
|---|---:|---:|
| ENCODE | 用户确认学完后设为 `5` | 未完成保持 `0` |
| 选择 | `20` | `5` |
| 有提示提取 | `40` | `5` |
| 无提示提取 | `60` | `20` |

ENCODE 不设额外测验；后面的 RETRIEVE 检验掌握情况。选择失败后可展示讲解，但不回到首次 ENCODE。已学习的轴不会因本表中的失败退到 0。

连续成功路径为 `0 → 5 → 20 → 40 → 60 → FLUENCY`。每次完成后返回调度器，不要求同一个词连续做完各档。

结果判定：

- 选择题匹配事先固定的正确选项。
- R 释义作答由 AI 对照本题目标释义判定，接受意思正确的同义表达。
- P 原词作答做规范化匹配，忽略大小写及首尾空格；只接受题目预先允许的词形变化。
- 答案、目标词义和判定要求在派发前确定。反馈后修改答案不能覆盖首次作答结果。
- 材料有问题、AI 无法判定或服务失败不是用户答错，不更新分数。

### 3. R FLUENCY

#### 材料

- 短文固定为 100 个英文词。
- 除目标词外，其他词汇符合用户水平。
- 目标词自然出现至少 5 次，保存实际出现次数。
- 本次有一个明确的计分目标词和 R 轴；文中其他词不自动获得分数。
- 提供两道题：目标词在文中的含义、整段核心意思或关系。避免用零碎细节记忆代替理解。
- 题目、正确答案和原文依据在派发前固定。

该任务测得的是目标词重复出现的材料中的阅读表现，不应宣称是所有陌生材料上的通用阅读速度。

#### 阅读与回看

1. 显示短文时开始阅读计时，不展示目标词释义。
2. 用户点击“读完”，暂停阅读计时并隐藏原文，显示理解题。
3. 用户可以返回原文；回看期间隐藏题目，继续累计阅读时间，不提前显示答案。
4. 结束回看后继续答题；提交后判定结果。

```text
reading_seconds = initial_reading_seconds + sum(rereading_seconds)
reading_wpm = text_word_count × 60 / reading_seconds
```

答题时间不计入阅读速度。计时失效或阅读中断，本次视为无效作答，不以不完整时间计分。

#### 分数回写

先检查材料和计时有效，再检查理解结果，最后计算速度分。

| 目标词含义题 | 整段理解题 | 处理 |
|---|---|---|
| 正确 | 正确，且 `reading_wpm ≥ 150` | 按速度直接更新 R 分数 |
| 正确 | 正确，但 `reading_wpm < 150` | 设为 `40` |
| 正确 | 错误 | 分数不变，记录整段理解未通过 |
| 错误 | 正确或错误 | 设为 `40` |

```text
F_R_new = min(100, 60 + (reading_wpm − 150) / 3.75)
// 仅在两题都正确、计时有效且 reading_wpm ≥ 150 时使用
```

150 / 225 / 300 wpm 分别对应 60 / 80 / 100 分。200 wpm 对应约 73.3 分，不论旧分为 60 还是 80，都直接写入本次表现分。存储和比较使用未舍入值，展示精度不改变调度结果。

不使用速度比加减分、正确率乘速度、平滑更新或历史最高分保底。进入 60 分不要求此前通过 150 wpm 测验；60 分也可能来自无提示 RETRIEVE，通过记录区分分数来源。

### 4. P FLUENCY

#### 材料与作答

- 用中文描述一组场景，要求以目标词对应的意思为核心复述题目内容。
- 不展示英文目标词，不提供可照抄的英文答案。
- 用户主动点击开始后计时，提交时结束；包含构思、输入、停顿和修改。
- 最终表达至少 30 个英文词，不能靠无意义重复凑字数。
- 必须出现并正确使用目标词，允许符合语境的词形变化。
- 一次只给明确的目标词和 P 轴计分。

题目应能自然引出指定目标表达。其他表达即使语义合理，也不满足本次“使用目标词”的要求；反馈应区分未满足任务要求与语言本身错误。

```text
writing_wpm = final_valid_word_count × 60 / writing_seconds
```

删除的内容不计入最终词数。少于 30 词时提示继续完成，不形成有效速度成绩。

#### AI 判定与分数

AI 分别返回目标表达结果、整体复述结果及原文依据：

- 目标表达：是否实际使用目标词或允许词形，含义、搭配和语法作用是否成立。
- 整体表达：是否复述中文题目要求的内容，语义连贯清楚；允许不影响理解且不涉及目标用法的小错误。

| 目标表达 | 整体复述 | 处理 |
|---|---|---|
| 通过 | 通过，且 `writing_wpm ≥ 25` | 按速度直接更新 P 分数 |
| 通过 | 通过，但 `writing_wpm < 25` | 设为 `40` |
| 通过 | 未通过 | 分数不变，记录整体表达未通过 |
| 未使用或使用错误 | 通过或未通过 | 设为 `40` |

```text
F_P_new = min(100, 60 + (writing_wpm − 25) × 40 / 35)
// 仅在两项通过、计时有效且 writing_wpm ≥ 25 时使用
```

25 / 42.5 / 60 wpm 分别对应 60 / 80 / 100 分，直接写入本次表现，可以升降。

#### 无效作答

- 从点击开始至提交不超过 5 秒，本次无效，不改分。这个规则只校验最短用时，不能识别所有粘贴行为。
- 中断视为没有答题，不改分；需重新开始才能产生有效计时。
- AI 无法判定、判分服务失败或材料错误时不扣分，保留作答供重试判分。
- 无效性检查先于质量扣分和速度计分，不能先按目标词缺失扣分再发现本次计时无效。

## 第三层：目标、状态与遗忘

### 1. 个人目标与导入

用户直接设置 R/P 分数目标 `target_R / target_P`，两轴都只允许设置为 `60–100`（含端点）。目标用于决定普通训练需求，不再通过速度目标推导，不随词频抬高。

```text
score_met_a = F_a ≥ target_a
```

取消毕业、保持力毕业门槛和永久退出训练。达到目标的轴退出普通竞争，但仍可进入急救集。目标调整不改已有分数，只重新计算需求。

导入规则：

- 无初始分数时两轴从 0 开始。
- 提供初始分数时，各轴必须满足 `0 ≤ F_a < 60`；不通过先验概率推导分数。
- 导入分数不构成实测证据，也不设置 `has_observation_a`。
- 导入后的首次任务与普通任务使用同一分数映射，无特殊诊断分支。
- 用户水平信息可用于材料难度匹配，不能据此跳过分数对应的档位。

导入分数小于 60，个人目标至少为 60，因此所有新导入轴都有正的目标缺口，可以按普通规则获得首次练习机会，不需要额外验证分支。目标默认值尚待确定；0 不是合法目标，也不表示关闭某轴。

### 2. 必要状态

```text
F_R, F_P                 // 当前训练分数
introduced(w)            // 是否已有实际教学或有效作答
has_observation_a        // 是否已有可归属的有效计分作答；ENCODE 不设置
H_time_a                 // 轴级记忆半衰期，初始 1 小时
last_ts_a                // 轴级时间锚
last_ts_any              // 词级最近有效练习或 ENCODE 完成时间
last_tick_any            // 对应全局任务位置
tick                     // 已完成的有效任务计数
target_R, target_P
```

不单独维护历史最高分。练习历史保留，可供查看，不参与任务类型选择。不能通过另一轴成功刷新本轴成绩、作答证据或时间锚。

### 3. 长期记忆与共享冷却

```text
Δt_a      = now − last_ts_a
Δt_any    = now − last_ts_any
Δtick_any = tick − last_tick_any

L_a(w) = 0.5 ^ (Δt_a / H_time_a)
R_a(w) = L_a(w)

C(w) = min(
  0.5 ^ (Δtick_any / 7),
  0.5 ^ (Δt_any / 20min)
)
```

`C` 是两轴共享的短时冷却，独立于长期记忆。`C ≤ 0.5` 表示经过 7 个其他有效任务或 20 分钟，任一满足即可。

遗忘预测不直接降低 F，也不设置待复核状态；只改变调度时机。没有时间锚的轴不计算遗忘紧迫度，也不能进入急救集。

记忆更新按目标词曝光增强，不再采用“失败减半”的规则。在有效完成的练习中，只要实际见到目标词，就增强本次目标轴的记忆半衰期；答错、部分通过或速度不足都不使半衰期减弱。ENCODE 完成和失败反馈中的目标词曝光同样属于学习，但同一实例只结算一次增强，不因反复查看反馈重复增加。

分数与记忆更新独立：分数可以因错误或速度不足退到 40，同时曝光使半衰期增强。没有目标词曝光时不凭空增加；不自动增强另一轴。具体增强幅度及曝光证据口径尚待确定，不默认沿用成功翻倍。

中断、跳过、退出或其他无效作答优先适用“不更新”规则：即使中断前已经见到目标词，也不更新本次半衰期、时间锚、冷却或 tick。

### 4. 普通优先级

```text
w_freq(w) = 1 + ln(1 + freq(w))
gap_a(w) = max(0, (target_a − F_a) / target_a)
urgency_a(w) = max(0, (0.9 − L_a(w)) / 0.9)²
P(w,a) = w_freq(w) × gap_a(w) × (1 + 9 × urgency_a(w))
```

没有时间锚时 `urgency = 0`。`freq` 的来源随词库记录，不能静默混用通用词频与书内词频。

达到目标后 `gap = 0`，不额外设置 0.05 等最低缺口，不参与普通竞争。后续由急救分支提供练习机会，因此通常等到严重遗忘阈值才再次出现。

## 第四层：调度器

设 `S` 为激活目标内的词（strict 模式），或全词库（默认模式）。材料只能决定某候选此刻能否派发，不能改变其应做的任务档位。

### 1. 急救集

```text
D = { (w,a) :
  w ∈ S
  且 introduced(w)
  且 has_observation_a
  且存在 last_ts_a
  且 L_a(w) < 0.2
}
```

不按毕业、目标已达成或轴已完成状态排除候选。

有可派发材料时，优先选 `D` 中 `L_a` 最低的词与轴，然后按当前 `F_a` 派发任务。急救独立于普通优先级，不要求 `gap > 0`，沿用急救优先于普通双闸门的分支结构。

例如 R 为 80 的词进入急救集，仍做 R FLUENCY；若目标词理解失败，作答后设为 40，下一次才做无提示 RETRIEVE。急救不预先扣分，不强制先做提取验证。

### 2. 普通复习

已引入且不在急救集中的候选检查：

```text
有时间锚时：R_a(w) ≤ 0.9
共享冷却：  C(w) ≤ 0.5
需求：      P(w,a) > 0
```

无时间锚的轴只检查已有词级冷却，不等待不存在的遗忘预测；完全没有练习锚的词不凭空施加冷却。

若复习池 `max P ≥ 1.0`，选择优先级最大的 `(w,a)`，再按分数取任务。

### 3. 引入新词与兜底

复习池为空或 `max P < 1.0` 时：

```text
从 introduced = false 且至少有一个 gap > 0 的词中，按 freq 选择新词
选择目标缺口最大的轴，同分按 R、P 顺序
按该轴 F 派发 ENCODE 或对应 RETRIEVE 档位
```

无可派发新词而复习池非空时，返回池中最大 `P` 的候选。不存在按先验选择任务的分支。

由于导入分数严格小于 60、目标范围为 60–100，新导入轴不会出现已达目标却无实测锚点的调度死角。

### 4. 材料不可用与 EMPTY

对选定候选优先取已有有效材料；不足时触发同档 AI 生成。有限重试仍失败，保留原因，暂时比较其他候选。不能将 FLUENCY 静默降为 RETRIEVE，也不能自动切换轴而不重新比较候选。

没有任务时返回 `EMPTY`，区分：

- 等待普通复习点或冷却。
- 达到目标，等待急救阈值。
- 材料准备中或生成失败。
- 当前范围没有可训练词。

等待时间按当前范围中有可用材料的候选，分别计算普通双闸门或急救条件下一次成立的时间，取最早值。急救使用严格条件 `L_a < 0.2`。等待期间 tick 不变，冷却按自然时间计算。

达到目标不是永久完成原因，不能从等待计算中删除已有实测锚点的达标轴。纯材料缺口返回材料原因，不能伪装成等待冷却；无可确定时间时 `wait = null`。

## 第五层：材料准备与 AI 保底

### 1. 导入时准备

导入后启动后台准备，优先保证当前分数对应的档位可练，再准备下一档：

- 确认目标词义与 gloss，准备 ENCODE 和 R/P 三档 RETRIEVE 初始材料。
- 接近或达到 60 时准备 R 短文及理解题、P 中文场景与判定要求。
- 已有材料使用后持续补充，保存使用记录，避免依靠背答案通过。
- 不要求导入时穷尽生成所有未来材料；用户水平、主题和词义变化时重新匹配。

### 2. 释义与校验

缺 gloss 时，用户手动填写或确认 AI 建议后保存。未确认的 AI 建议不是正式释义，不用于生成正式判分依据。修改 gloss 后，使旧词义对应材料失效并重新生成。

材料状态至少区分准备中、可用和生成失败。生成后检查目标词义一致、答案明确、干扰项合理、提示符合档位要求，以及 FLUENCY 的长度、难度和目标词使用要求。P 场景不得泄露英文目标词。生成成功不等同于校验通过。

### 3. 练习时保底

已有有效材料 → AI 生成同档材料 → 校验 → 缓存并派发。生成失败或校验失败可有限重试；仍失败则记录原因并尝试其他候选，不改变分数。

作答后的判分失败与材料生成失败分开处理：保留用户作答，允许重试判分，不要求重新表达，也不提前写入失败成绩。

## 第六层：实例、回写与记录

### 1. 任务实例

每个实例在派发时固定：

```text
instance_id, definition_id, word_id, axis,
type: ENCODE | RETRIEVE | FLUENCY,
stage: encode | choice | cued | free | fluency,
purpose: introduce | review | recover,
score_before, material_id, material_version,
target_sense, payload, grading_requirements, timing_protocol
```

`purpose` 只解释为什么此刻练，不改变类型、档位或评分。一次总体结果不能自动更新两轴或文中所有词。

### 2. 状态回写

有效 ENCODE 完成或有效作答只结算一次：

1. 按任务结果表更新目标轴 F。
2. 设置词级 `introduced`；只有有效提取／流利作答设置目标轴 `has_observation_a`。
3. 按目标词曝光增强规则更新该轴半衰期，并刷新该轴时间锚；不得因作答失败而缩短半衰期。
4. 更新共享 `last_ts_any`、`last_tick_any = tick + 1`，全局 tick 增加一次。
5. 原子保存前后状态和事件，重复请求返回已处理结果。

分数保持不变的有效作答仍需记录，不能与无效作答混淆。反馈讲解不生成另一笔计分或额外 tick。未完成 ENCODE、无效计时、中断、材料错误及服务失败不改变 F、半衰期、时间锚、冷却或 tick。

### 3. 中断、跳过与退出

FLUENCY 中断后，本次视为未作答：不改分，不更新记忆半衰期、时间锚和冷却，不增加 tick；保存中断原因。重新开始时重新计时，不能拼接中断前后的用时生成成绩。具体中断检测事件仍需明确，不能仅凭长时间没有输入推断用户已离开。

保留显式跳过，不支持延期：

- 跳过将当前实例标记为 skipped，记录一次 `task_skipped`，签发下一任务。
- 不改变 F、半衰期、时间锚、冷却或 tick；不额外降低优先级。
- 被跳过的词重新参与正常调度，仍最优时可能再次出现。
- 重复跳过请求不重复记事件。
- 退出与跳过分开记录，实例终态互斥；跳过后不再记退出。
- 未提交上滑仍忽略，不解释为跳过。

```text
跳过率 = skipped / (attempts + skipped)
退出率 = exits / (attempts + exits + skipped)
```

展示分子和分母；中断／无效作答不计入有效 attempts。

### 4. 练习历史

记录至少包括：

- 实例、目标词、轴、任务类型、档位、用途、材料及版本、时间。
- 用户答案、每个检查项结果、AI 判定依据和失败／无效原因。
- 文本词数、目标词出现次数、首次阅读与各次回看用时、写作用时、实测 wpm。
- 更新前后分数及原因、记忆与调度状态变化。
- completed / skipped / exited / invalid 等结果，及判分重试信息。

缺少测速记录为 null，不沿用上次速度。保存历史用于查看变化，不单独维护历史最高分状态，也不用历史最高分保护当前成绩。
