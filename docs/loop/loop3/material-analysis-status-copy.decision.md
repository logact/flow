# Loop3 材料分析状态文案决策

## 决策

- 对应人工评审第 5 条：材料列表和详情页对同一状态使用一致文案：`pending` 显示“分析中”，`analyzed` 显示“分析完成”，`failed` 显示“分析失败”。没有分析记录时，列表显示“未分析”，详情显示“未开始”。
- `pending` 超过恢复期限时仍属于未完成分析状态；主状态保持“分析中”，同时附加“已超时，可恢复并重试”说明和恢复操作，不把它误标为正常排队或未分析。
- 统一状态映射应避免列表和详情分别维护相互矛盾的标签。

## 实施范围

- **Domain**：不改变分析状态枚举及持久化结构。
- **Service**：沿用现有 pending 超时判定与安全重试流程。
- **UI**：抽取或共用状态文案映射；列表和详情遵循同一标签及超时解释。
