# Loop3 知识库字体与层级样式决策

## 决策

- 对应人工评审第 6 条：全局知识点库列表中的词条标题、释义、熟练度/词族信息、来源材料和操作入口应有清楚且一致的字体层级；避免通用列表文本与标题、来源链接显得突兀。
- 继续使用应用现有字体和暗色主题，不引入新的字体依赖或独立视觉主题。中文和英文混排应有舒适行高，长词条及材料名称允许换行。
- 窄屏下信息层级和操作可读性优先于紧凑排列；来源筛选样式与列表条目保持一致。

## 实施范围

- **Domain**：不涉及。
- **Service**：不涉及。
- **UI**：为知识点列表及来源筛选区定义一致的标题、正文、辅助信息、链接和操作样式，并检查窄屏换行。
