# Loop3 材料详情手动启动分析决策

## 决策

- 对应人工评审第 4 条：打开材料详情或刷新详情只读取材料及分析状态，不自动启动或重启分析。分析必须由用户通过明确按钮发起。
- 当前详情 GET 不会触发分析，分析由 `POST /api/materials/[id]/analysis` 启动。页面对既有 pending 状态轮询；超过 2 分钟后显示恢复重试入口。该行为需要在页面状态文案和按钮层级上清楚区分。
- 未开始时提供“开始分析”；运行中展示“分析中”及自动更新提示，不提供可误触的启动按钮；失败或超时后提供明确重试/恢复入口，并复用原材料。

## 实施范围

- **Domain**：不涉及。
- **Service**：保持 GET 只读，POST 显式启动并保留当前并发去重与超时恢复约束。
- **UI**：明确展示未开始、分析中、失败/超时和完成状态；只有用户点击显式操作才发起分析。
