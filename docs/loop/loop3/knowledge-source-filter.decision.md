# Loop3 知识库来源材料筛选呈现决策

## 决策

- 对应人工评审第 3 条：全局知识点库保留按来源材料多选筛选的能力；选择多个材料时展示任一所选材料关联的知识点，清除筛选后恢复全量列表。
- 当前页面与 API 已实现多选和筛选语义。本条关注控件在窄屏下的可见性和易操作性，不重复增加另一套筛选状态。
- 筛选选择应持续显示，且清除入口在有选择时可直接发现；布局不得挤压搜索框、排序控件或知识点列表。

## 实施范围

- **Domain**：不涉及。
- **Service**：沿用当前 `sourceId` 多值查询行为。
- **UI**：调整来源筛选区域的布局、标签间距和选中反馈，保证窄屏可读、可操作。
