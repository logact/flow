# 学习续接与答题交互决策

## 决策

- 对应人工评审第 3 条：离开并返回首页后，续接到当日第一个未完成任务（即最近完成任务之后的位置）；没有未完成任务时保留今日完成状态。不能每次都把滚动位置重置为队列第 0 项。
- 对应人工评审第 7 条：判错后在当前题目上清楚展示判题 feedback；判对时不展示面向纠错的文本，避免让正确答案看起来有问题。
- 对应人工评审第 8 条：需要回忆目标词的题目不能在题干或提示中直接泄露目标词本身；用释义、上下文或其他不包含答案的线索表述。
- 对应人工评审第 9 条：选择题选项在呈现前打乱顺序，正确选项身份始终由选项 ID 关联，不能依赖答案固定在 A/B。
- 对应人工评审第 10 条：答案提交并等待判题期间显示明确的处理中动画/状态，防止用户误以为没有提交。

## 调查依据

- 首页加载后 `activeSlide` 固定从 0 开始；“继续学习”按钮虽定位到首个未完成项，但再次返回首页不会自动定位。
- 当前结果卡片不区分对错，始终展示 `result.feedback`。
- 当前生成约束未要求提示语避开目标词；截图题干直接写出了目标词 `path`。
- 当前选择卡按生成数组原顺序显示；提交控件没有等待判题的动画状态。

## 实施范围

- **Domain**：选择题顺序变化时保留 option ID 与正确答案的绑定；不改变判题结果。
- **Service**：不新增判题规则；生成任务时明确校验题干/提示不直接暴露目标词，并继续传递原始判题反馈。
- **UI**：恢复至首个未完成任务；仅在判错时突出纠错 feedback；提交等待中显示动画与禁用重复提交状态。
