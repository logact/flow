# 初始词汇流利度规则

## 背景

新知识点初始化时，系统根据学习者当前词汇估计和知识点所属词频段，推导 R（接受）与 P（产出）维度的初始流利度。原规则在认识概率低于 0.7 时仍会给出非零 R 分数，且最高档给 R=50。现需让低于阈值的知识点从零开始，并调整达到阈值后的起始分。

## 决策

- 以学习者当前词汇估计中，该知识点所属词频段的 `knownProbability` 作为认识概率。
- 认识概率低于 0.7 时，R、P 两个维度的初始流利度均为 0。
- 认识概率达到或超过 0.7 时，R 初始流利度为 40。
- 达到阈值时，P 按既有“产出比接受低一档”的规则初始化为 20。
- 缺少当前词汇估计、匹配的词频分类，或估计中找不到对应词频段时，认识概率按 0 处理，因此 R、P 均初始化为 0。
- 词频分类必须与当前词汇估计使用相同词表及版本；不匹配时仍按领域校验规则拒绝派生，不能混用不同版本的数据。

## 实施方向

- **Domain**：调整初始流利度推导，使概率阈值为 0.7，输出仅为 R/P 均为 0 或 R=40、P=20；同步检查新词准入预测使用的初始维度，确保行为一致。
- **Service/Application**：继续由初始化流程加载当前词汇估计和对应词频分类，并将领域推导结果用于学习状态初始化；无需新增服务规则。
- **UI**：不涉及页面或交互变更；现有流利度展示消费初始化后的 R/P 值。
- **验证**：覆盖概率低于、等于和高于 0.7，缺少分类/词频段，以及新词准入预测与正式初始化一致的情形。

## 验收标准

- 概率小于 0.7 时，R、P 初始值都为 0。
- 概率等于或大于 0.7 时，R=40、P=20。
- 缺少可用分类证据时，R、P 初始值都为 0。
- 正式初始化和新词准入预测采用同一规则。
