# ENCODE 发音与音标决策

## 决策

对应人工评审第 6 条：ENCODE 页面展示可获得的目标词 IPA，并提供对应发音播放。

- **数据源**：使用免费的 [Free Dictionary API（dictionaryapi.dev）](https://dictionaryapi.dev/) 查询英语词条：`GET https://api.dictionaryapi.dev/api/v2/entries/en/{lemma}`。从响应的 `phonetics` 中读取音标文本和音频 URL。响应的发音项通常位于词条级而非义项级；当数据能明确关联目标词条/词性时才附值，无法确认时不猜测。
- **查询时机**：材料分析完成词义消歧并确定知识点 lemma/词性后，由应用服务查询一次并缓存结果。不得在每次生成 ENCODE 任务或用户每次点击播放时重新请求词典 API。
- **数据归属**：IPA、音频 URL、来源标识/来源链接及查询时间作为可选的词条级发音元数据存于知识点；发音是词条属性，不属于单独 sense。生成 ENCODE 任务时从知识点复制元数据到任务快照。
- **失败处理**：词条无匹配发音、API 不可用或响应无效时，分析及任务生成继续成功，发音元数据保持缺失，并允许之后重新查询；UI 明确显示“音标暂缺”并禁用播放。
- **播放和许可**：播放已缓存的音频 URL，不使用浏览器合成语音替代词典真人/词典录音。保留来源标识（dictionaryapi.dev）及查询链接并提供来源说明；不下载或重新分发音频文件。该公共 API 免费且无需 API Key，但没有明确 SLA，调用失败不能阻断学习流程；上线前需复核数据和音频的署名/使用许可。

## 实施范围

- **Domain**：为词条增加可选发音元数据，至少可表达 IPA、音频 URL、来源和查询时间；缺失是合法状态。
- **Service**：在知识点解析完成后调用词典查询服务；按 lemma/词性匹配并缓存；处理超时、未收录、格式异常和重试，不让外部服务失败导致材料分析或任务生成失败。
- **UI**：在 ENCODE 页面显示 IPA；通过音频 URL 播放；缺失、播放中及播放失败时提供清楚状态，并展示数据来源信息。
