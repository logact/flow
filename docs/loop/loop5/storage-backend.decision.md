# 运行时存储后端选择决策

## 决策

- 应用启动时通过服务端环境变量 `FLOW_STORAGE` 选择学习状态仓储：`memory` 使用进程内存仓储，`sqlite` 使用 SQLite 仓储。
- 未设置时默认使用 `memory`，保持现有运行行为；不接受的值应在启动初始化时明确报错，不静默回退。
- 两种后端使用同一套应用用例和运行时种子初始化。SQLite 模式使用现有 SQLite 路径配置/默认路径及迁移机制；切换后端不自动迁移或删除另一后端的数据。
- 此决策取代 loop2“运行时不启用 SQLite”的当前运行限制；SQLite 实现仍需在实施时验证运行时集成与初始化/失败处理。

## 范围

- 仅服务端读取环境变量，不暴露给浏览器端。
- 统一仓储接口类型，运行时不依赖具体仓储类。
- 更新启动配置说明，并覆盖默认、显式 memory、显式 sqlite 和无效值行为。
