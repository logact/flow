# 第 20–22 条实现口径

> 运行时仓储口径已由 [loop2 人工评审第 8 条](../loop2/huaman-reivew2.record.md) 更新：当前应用恢复使用进程内 `InMemoryAppRepository`。以下 SQLite 描述记录的是 `31e326f` 时的实现，不代表当前运行时；SQLite 仓储代码保留但不接入应用。

## 知识点库熟练度与记录

- 列表“熟练度”按当前 R、P 流利度算术平均值四舍五入为整数；按高到低排序，未初始化的项目排在已初始化项目之后。
- 详情页未来复习日期直接取当前 R/P `ReviewSchedule.dueAt`；已毕业维度不显示待复习安排。尚未初始化的知识点显示无计划状态。
- 学习记录按作答接收时间升序展示；分数变化只展示结算返回的实际 `fluencyChanges`，不插值或推断缺失变化。

## 答对反馈

- 正确答案的全屏庆祝反馈显示 2.4 秒，学习流程在 2.5 秒后继续；错误或部分正确答案不触发该反馈。
- `prefers-reduced-motion` 下保留答对状态和自动继续时间，但由全局减少动态效果规则移除动画。

## 学习进度持久化

- 当前单学习者运行时的完整领域状态由 SQLite 保存，默认文件为 `.flow/flow.sqlite`，可用 `FLOW_DATABASE_PATH` 指定其他位置。
- 学习状态与复习计划在结算时随 attempt 一起写入 SQLite；同一任务已有作答时重试沿用已有 attempt，不重复推进进度。每日任务刷新作为结算后的独立步骤返回结果，不回滚已经成功保存的结算。
- 状态落库失败时 API 返回失败，客户端保留未完成反馈，不将该次作答展示成成功持久化。
