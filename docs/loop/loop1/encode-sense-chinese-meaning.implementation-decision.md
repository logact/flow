# ENCODE sense 中文释义实施决策

## 决策

中文释义存储在具体知识点的 sense 数据上。新建或补全 sense 时，使用项目已配置的 OpenAI 兼容 LLM 提供者，将该 sense 的英文 definition 翻译为简明中文释义并持久化；同一个 sense 后续材料关联复用已保存值，不为每个 ENCODE 任务重新翻译。

没有配置 LLM、翻译失败或历史 sense 尚未补全时，中文释义保持缺失并以明确的“中文释义暂缺”状态展示。不得把同词的其他 sense 释义作为回退。保留英文释义作为独立数据，ENCODE 任务快照可引用已保存释义，但不能成为释义事实来源。

## 理由与边界

当前 WordNet sense inventory 只提供英文 gloss，仓库没有可用的中文释义词典或翻译服务。复用已配置 LLM 是当前项目内唯一的 sense 级翻译能力。缺失状态保证系统不会伪造、串用或把未持久化的翻译冒充为 sense 数据。

该决策只涉及 sense 中文释义，不改变 ENCODE 英文释义、例句和例句翻译的生成方式。既有数据采用兼容性补全；后续分析/访问可补译，但已有历史数据在补齐前必须明确显示缺失。
