# 材料保存与分析解耦实施决策

## 决策

材料导入请求只负责提取文本、保存材料原始信息并建立 `pending` 分析记录；导入成功后不自动运行术语分析或 AI 消歧。用户在材料列表或详情中显式启动分析。分析失败保留材料和失败状态，用户可针对同一材料单独重试，不创建新材料。每份材料同一时刻只允许一个分析请求运行；重复启动返回当前分析状态。

分析状态复用领域模型已有的 `pending`、`analyzed`、`failed` 值。分析完成后只把 `analyzed` 的材料提供给目标创建及材料关联流程。分析失败显示可理解的失败状态和重试入口；材料保存失败则不显示为已保存。

## 理由与边界

材料与分析是不同操作。保存后即使分析服务不可用，用户仍能保留材料记录；同一材料重试分析不会造成重复导入。分析结果按版本单独保存，保留既有材料与历史分析兼容性。

该决策只规定材料持久化、显式分析触发、状态反馈和重复请求处理；分析算法与知识点筛选口径不变。
