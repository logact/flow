# 错题答案与原因反馈需求

## 需求

学习者答错题目后，应看到该题的正确答案，以及解释为什么答错/正确答案为何成立，帮助学习者理解和纠正错误。

## 讨论背景

当前任务内容中已有部分正确答案和解释，但提交结果及页面反馈未必能将其按题目返回和展示。实现可能涉及 domain、application service、API 响应及学习页面组件。

## 下个 loop 需要仔细讨论

- 哪些题型纳入范围：主动提取选择题、提示/自由作答题、阅读理解选择题与自由题等。
- “解释为什么错”的含义与来源：现有答案解释是否足够；自由作答是否需要针对用户答案生成具体纠错理由。
- 反馈展示时机与形态：逐题或整题展示、部分正确处理、答案和解释的呈现方式。
- 答案及反馈的持久化与 API 边界：确保答题前不泄露答案，并让首次提交、重试和历史结果一致。
- 兼容 AI 判题与规则判题，以及缺少参考答案/解释时的处理方式。
- 具体 domain/service/API/UI 修改范围和验收标准。
