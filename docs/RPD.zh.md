# 概述
本应用是 Paul Nation「四股线（Four Strands）」学习理论的一次实践。

## 基本用户流程

### 场景一（主流程）
1. 用户设定一个目标，目标可以是读完一本书、通过一场英语考试……
2. 系统引入相应材料，将其拆解为需要学习的知识点，为每个知识点设定需要达到的流利度目标，并将其作为进度进行追踪。
3. 用户只需像刷抖音一样滑动屏幕，完成系统分配的每一个学习任务。

### 任务生成与分配的核心算法

#### 我们要实现的目标

1. 间隔记忆——冲刷短时记忆缓存。
2. 均衡设计四类任务：MFI（听、读）、MFO（说、写）、LRL（语音、语法、词汇）、FD（流利度发展）。
3. 针对具体目标的自适应任务设计。
4. 用分数衡量用户水平。

#### 领域模型（Domain Model）

**1. 知识点（Knowledge Point, KP）** —— 学习的最小单元。目前 KP 都是词汇*语块*（单词/词组）；模型在设计上预留了扩展，之后可以把语法点、语音点作为新的 KP 类型加入。

| 字段 | 含义 |
|---|---|
| `chunk` | 目标语言项目本身 |
| `meaning` / `scene` / `slots` / `substitute` | 学习内容：释义、场景例句、可搭配槽位、近义替换词 |
| `step3_sentence` / `step4_sentences` | 创建目标时为每个 KP 生成的任务材料 |
| `freq` | 在源材料语料中的词频 —— 队列优先级和分数聚合中的重要性权重 |
| `fluency`（F_P）/ `fluency_r`（F_R） | 0–100 流利度，**按方向各持一份**——F_P 产出（写作），F_R 接受（阅读）：认出绝不等于会用，两个方向各自记分。对外 headline F = **min(F_R, F_P)** |
| `target_in` / `target_out` | **每词的个人流利度终点**（阅读方向 / 产出方向），入库时由目标画像推导并物化（见「目标锚定的流利度」）；毕业判定与缺口计算的基准 |
| `stability_tick` | tick 钟共享半衰期（H_tick）——短时缓存是形式级的，任一方向的练习都会刷新它 |
| `stability_time` / `stability_time_r` | 时间钟按方向的半衰期（H_time_P / H_time_R）——再认与产出是两条独立的记忆痕迹，各自遗忘 |
| `last_tick` / `last_ts` / `last_ts_r` | 计算经过量 Δ 的锚点——tick 锚点双向共享，时间戳按方向各自记录 |

> 不再有 `state`、`ready_at_*` 门、`due_at`。过去的流水线状态机被每个 KP 上的一个连续分数取代。

**派生段位（实时计算，仅作展示，不参与派发）。** 段位由 headline F = min(F_R, F_P) 现算，用于进度条和仪表盘；**题型不再由段位查表决定**，而由任务库的资格谓词直接决定（见 §5）：

| 段位 | 条件 | 含义 |
|---|---|---|
| NEW | 从未尝试 | 未学 |
| LEARNING | F < 50 | 仅再认 |
| CONSOLIDATING | 50 ≤ F < 75 | 费力但可靠 |
| INTEGRABLE | F ≥ 75 且未整合 | 可入批次 |
| MASTERED | F ≥ 80 且已整合 | 双向自动化 |
| GRADUATED | 双轴均达个人目标且双向 H_time ≥ 30 天 | 毕业——扛住了长时遗忘 |

**2. Tick 时间（`global_tick`）** —— 逻辑时钟，**永久单调递增**地累计已完成任务的数量（不归零）。自某个 KP 上次尝试以来经过的 tick 数，衡量短时缓存被穿插的干扰任务冲刷的程度——缓存的**干扰通道**。

**3. 间隔时间（`last_ts` / `last_ts_r`）** —— 自上次尝试以来的物理 wall-clock 时间。它同时喂两条通道：缓存的**时间通道**（H_cache ≈ 20 分钟，工作记忆痕迹自然消散）和长时遗忘通道（H_time，1 小时 → 天 → 周）。睡眠免费完成两种衰减。

> 缓存的双通道是**并联**关系：干扰任务能冲掉它，纯粹流逝的时间也能冲掉它——练完三小时再回来，即使中间一个任务都没做，热缓存也早已散尽。旧模型只有干扰通道，不得不用「会话内/跨会话」特判来打补丁；双通道之后特判消失，隔夜只是 Δt 很大的普通情形。
>
> **系统没有「会话」概念。** 调度器只有两条时钟（tick、wall-clock），不读任何练习段落的边界：tick 永久单调，缓存冷却靠干扰∥时间，长期遗忘靠 Δt。用户「坐下来练一段」是行为层的自然模式，不需要系统知道；分析层若需要练习段落统计，可从 events 的时间戳间隔事后切分（间隔超过阈值即分段），不留专门的事件类型。

**4. 流利度分数（Fluency score）** —— 每个 KP 的 0–100 自动化程度估计（提取速度 + 准确率），**按方向各持一份**：F_R（接受/阅读）与 F_P（产出/写作），只由对应方向的计分任务更新。驱动聚合的 headline 分数是 min(F_R, F_P)——一个 KP 的流利度由它较弱的方向决定。为什么拆 R/P 而不是听说读写四项：本产品只覆盖读写能力，R/P 是唯一会改变调度决策的拆分方式；按模态实测的 wpm 只作展示指标，不作分数。

**5. 分数驱动队列** —— 每个 **(KP, 方向, 将派的任务)** 三元组是一个候选，每次请求重新计算优先级；队列就是所有候选按它排序的结果。三元组而非二元组的原因：任务由资格谓词现查（同一根轴在不同 F 下派不同题型），**先定任务，后算 P**——一次扫描同时得到「练哪个词、练哪个方向、派什么题型」。

可提取性（KP 还剩多少可以提取）：

```
C     = min( 2^(−Δtick / H_tick),  2^(−Δt / H_cache) )      ← 短时缓存残留（双通道并联，共享）
L_a   = 2^(−Δt_a / H_time_a)                                 ← 长时记忆痕迹（按方向独立）
R_a   = C × L_a                       a ∈ {R, P}             ← 服务就绪度：缓存冲刷 × 痕迹尚可
```

两个量分工明确：**R_a 只回答「现在值不值得服务」**（成熟闸门）——缓存被 4–5 个干扰任务（或 ≈20 分钟）冲刷后 R 即掉落，新词引入几个任务后就能回头练，复习与生词引入自然交错。而**「是否已死」（RELEARN 路由）、「逾期多久」（urgency）、「间隔后还剩多少」（计分 R_服务）都必须看 L_a**——缓存冷（C→0）是冲刷到位而非遗忘，拿 R_a 判死会让隔夜的全词库集体被误判进重编码。

优先级：

```
gap     = max(0, target_a − F_a) / target_a        需求度：距个人终点的归一化缺口；
                                                     达标但 H_time < 30d 的轴取 MAINT_GAP（0.05）
                                                     转入维护复习，保持力验证后才归零退场
urgency = ((RIPE_R − L_a) / RIPE_R)²               紧迫度：长时痕迹的逾期程度（L 越小越急），平方加速
P       = w_freq × gap × (1 + URGENCY_GAIN × urgency)

w_freq   = 1 + log(1 + freq)    重要性：高频 KP 更值钱
```

为什么 urgency 是逾期平方项而不是 (1−L)：遗忘存在一个**最优服务窗口**（Bjork 合意困难：遗忘开始之后、彻底遗忘之前）。刚成熟的词不急；逾期越久，提取失败 → F 回落、H 减半的重学成本越高——成本是加速上升的。而 L 已经跌穿 `RELEARN_R`（0.2）的词不是「需求更旺」，而是「已经违约」：它不再配提取/速度任务，直接路由回重编码（Step 1+2 式）。路由以 **P 轴的 L** 为准——重编码会重置双轴，只配得上「产出痕迹也死了」；R 轴单独死亡（F_R 托底不刷新 `last_ts_r`，L_R 自然衰减到零）走正常竞争派 STEP4R/MFI 重测即可，不拖 F_P 陪葬。文献锚点见文末。

**不设分线配额系数。** 四股线（MFI/MFO/LRL/FD）的均衡不由调度器强制——它是需求驱动的涌现结果：某条线练得少，对应方向的 F 停滞、gap 扩大，该线的任务自然赢得竞争；配额制反而会在没有真实需求时硬塞任务。四股线的作用是指导**任务库的覆盖面**——每条线都要有真实任务可派（MFI 落地后首次齐备）。

任务库（替代旧的段位→题型查表）：

| 任务 | 喂轴 | 分线 | 资格谓词（eligible） |
|---|---|---|---|
| Step 1+2（STEP12） | 双轴播种 | LRL | 从未尝试（last_ts = 0） |
| Step 3 语境提取 | 主 P，经 P⊃R 迁移托底 F_R | LRL | 已播种 |
| Step 4 限时写作 | P | FD | F_P ≥ 50（准确性底线 ACCURACY_FLOOR） |
| Step 4R 限时速读 | R | FD | F_R ≥ 50 且材料 ≥ READ_MIN_WORDS |
| MFI 可理解输入 | R | MFI | F_R ≥ 50 且有书源语料 |
| Part B 批次集成 | P | MFO | 门禁制（见调度循环），不参与 P 竞争 |

资格谓词保证「先准确后速度」无需档位：F 低于 50 时速度任务不可派，候选自然落回提取类任务。材料太短（词表导入只有语块本身）的 KP 没有可测量的阅读构念：R 方向无任务可派，F_R 镜像 F_P。同一根轴上各候选的 gap/urgency 相同、P 必然相等，平局由**任务秩**裁决——信息更丰富的构念优先：P 轴 STEP4 > STEP3，R 轴 MFI > STEP4R。

调度循环：

1. **Part B 优先**：双轴 F 均 ≥ 75（INTEGRATE_FLOOR）且未整合的 KP 凑满 5 个 → 立即触发批次任务。
2. **成熟候选其次**：三元组过双闸门——`R_a ≤ 0.9`（RIPE_R，遗忘成熟）且 `C ≤ 0.5`（CACHE_COLD，缓存冷却：≈4–5 个干扰任务冲刷，或 ≈20 分钟以上自然冷却）——取 P 最大者派发。
3. **新词引入（插空）**：满足任一条件——a) 复习候选池空；b) 最高 P 低于 NEW_WORD_BYPASS（没有紧急复习时插空引入）——从激活目标按 `freq` 降序取下一个 NEW KP。引入任务同时充当冲刷其他所有 KP 缓存的干扰材料。
4. **彻底没有 → EMPTY**：报告最近的成熟时间（所有词所有轴取 min），而不是提前硬刷。

为什么复习严格优先于新词：复习是**时间关键资产**——错过服务窗口就是重学成本；新词 last_ts = 0，没有任何东西在衰减，等多久都不亏。

引入**不设配额或库存上限**：每引入一个词，它约一小时后（H_time 种子）就成熟为复习候选并参与 P 竞争，bypass 阈值随之收紧——引入行为本身制造未来的复习压力，系统形成自我限速的负反馈闭环，无需外加会计式上限。**校准观察项**：低词频新词（freq = NULL → w_freq = 1）刚播种时 P ≈ 0.8，可能低于 BYPASS 而堵不住连续引入；若 events 显示冷启动暴饮（大量新词连续引入后次日通过率崩盘），再回到这个点加约束。

GRADUATED 段位的 KP 永远不再进入队列——目标被可验证地达到后，练习停止（见「目标锚定与毕业规则」）。

为什么它能取代状态机：

- **间隔是涌现的，不是强制的。** 刚练过的 KP：C ≈ 1 → R ≈ 1 → 闸门关闭。穿插的任务和流逝的时间让 C 与 L 衰减，它恰好在需要重测时浮回来。
- **失败自我纠正。** 失败的 attempt = 0 会拖低 F、缩短 H；KP 自动开始抽到更简单的任务——不需要降级规则。严重逾期（L < RELEARN_R）则显式路由到重编码——承认它已死，别测了。
- **没有边界要处理。** 缓存的时间通道让隔夜自然冷却，`R_time` 持续衰减，任何时刻的优先级扫描都自然浮出该练的词——不需要门禁折算，不需要 tick 归零，不需要知道用户什么时候开始、什么时候离开。
- **每个 KP 每个方向一个旋钮。** 所有自适应（目标难度、复习时机、速度压力）都通过 F、H、target 表达——在学习科学认为痕迹独立的地方按方向拆分（R/P），在认为不独立的地方共享（tick 缓存）——调系统 = 调一条计分流水线。

作用域规则：

- **新 KP** 只从*当前激活目标*（`active_goal_id`）中引入——学习火力集中在用户选定的目标上。
- **复习不看目标**（默认）：任何目标的成熟 KP 纯按 P 竞争——遗忘不等人。用户可开启「只学当前目标」（`goal_scope_strict`）：复习与 Part B 批次同样限定激活目标，代价是其他目标的在学词暂停复习、间隔拉长。
- **已知词不学两遍。** 词汇量测量的逐词答案落 `known_words` 表；导入目标时命中词不从 NEW 学起——高位播种（F_P=15、F_R=60 知识确认线），直接进入复习队列做一遍提取验证后快速爬升（自报认识不等于真会，留一次验证而非直接跳过）。抽样测量（~40 词/次）之外，「假定已知」由频率序词表（`data/word-rank.txt`，行号即 BNC/COCA 排名）按 `vocab_estimate` 取 top-N 推广——同一份词表也是 MFI 已知覆盖率（停用词 + 短词 + 假定已知 ∪ 已学 token）与按差距选材的底座资源。

每次尝试都追加到 `events` 日志（`tick`、`ts`、`kind`、`word_id`、`result`，延迟记在 `detail`）——既是审计轨迹，也是校准数据集。

#### 学习任务类型

股线标签沿用 Nation 的四股线：**MFI**（意义聚焦输入）、**MFO**（意义聚焦输出）、**LRL**（语言聚焦学习）、**FD**（流利度发展）。

##### Step 1+2 —— 引入任务（当前实现：`STEP12`）
**描述** 用户首次接触新 KP：阅读语块 + 释义 + 场景例句，然后根据释义提示盲打出语块。
**类型** LRL · 阅读 → 写作
**是否计分** 否（只做拼写检查；打错当场重打）
**效果** 初始化 KP：双轴同时播种（F_P = 15，F_R = 8——见过拼写但尚未验证再认），H_tick ≈ 4 个任务，H_time_P = H_time_R ≈ 1 小时

##### Step 3 —— 语境提取任务
**描述** 经过间隔后，KP 的场景例句再次出现，语块被挖空；用户回忆并产出它。
**类型** LRL · 阅读 → 写作
**方向** P（由义产形）——主更新 F_P；通过时经 P⊃R 迁移把 F_R 托底到 A×60（这就是 F_R 从播种值 8 爬到 50 的爬坡路径）
**是否计分** 通过/失败 → 更新流利度
**效果** 通过把 F_P 推向 50（被托底的 F_R 过 50 后，R 方向的速度任务解锁）；失败拖低 F_P 并把 H_time_P 减半；拼错 = 当场重做 Step 2

##### Step 4 —— 快速产出任务
**描述** 限时产出：用户在自适应速度游标设定的时间预算内用该语块写 2–3 个句子（4/3/2 式压力，自动化）。测量响应延迟并换算 wpm。
**类型** FD · 写作
**方向** P——只更新 F_P；通过时经 P⊃R 迁移把 F_R 托底到 A×60
**是否计分** 准确率 + 延迟 → 流利度分数的主要输入
**速度标尺** 打字模态：25 wpm（二语流利下限）→ 60 wpm（母语者平均上限）；游标封顶 = 目标画像的 writing_wpm

##### Step 4R —— 限时速读任务
**描述** FD 的阅读半边：KP 的三个场景句（step4_sentences）作为速读篇章，用户在阅读游标设定的时间预算内一口气读完，然后理解自评（自报读懂才算有效测速——防止扫读刷分）。阅读 wpm = 篇章词数 / 用时，按目标画像的 reading_wpm 锚定打分。倒计时归零不停表：读不完可以继续读，超时本身会拉低实测 wpm、阻止游标加压。
**类型** FD · 阅读
**方向** R——只更新 F_R，不反向迁移到 F_P
**是否计分** 理解自评 + 实测 wpm → F_R 更新；预算内读懂 → 阅读游标 +5%（封顶 reading_wpm），没读懂 → −10%（保底 v_floor_reading）
**速度标尺** 150 wpm（能获得大部分意思的最低速度，低于此在逐词解码）→ 300 wpm（母语者上限 250–300 取顶）

##### MFI —— 可理解输入任务
**描述** 从书源原文切一段 150–300 词的连续篇章，要求目标 KP 出现且段内已知词覆盖率 ≥ 95%（已知 = 停用词 + 短词 + 词频表前 vocab_estimate 词 ∪ 测量确认词 ∪ 已学 token）；用户在阅读游标设定的时间预算内通读，然后做主旨理解自评（三选一，选项由相邻段落句生成）。补全四股线中长期空缺的 MFI。
**类型** MFI · 阅读
**方向** R——更新 F_R；阅读游标按同一套棘轮规则加压/泄压
**资格** F_R ≥ 50 且有书源语料；词表/IELTS 来源无书文时不可派，候选自动落回 Step 4R
**是否计分** 理解正确 + 阅读 wpm → F_R 更新

##### Part B —— 整合写作任务
**描述** 批次门禁：双轴 F 均 ≥ 75 且未整合的 KP 凑满 5 个后，用户把各词的示范句串成微文、看着骨架复述。
**类型** MFO · 写作
**方向** P
**是否计分** 每个 KP 全对才算过 → 更新流利度
**效果** 通过 → KP 认证为已整合，F_P 保底 80，H_time_P 跳到 1 天档；漏掉的 KP 的 F_P 下跌，自动回到低档任务

##### （搁置——超出读写范围）影子跟读任务
**描述** 用户实时跟读场景例句的音频，按完成时间与音频时长的对比评分。搁置原因：Nation 剖面中的口语形式侧面目前不在范围内。
**类型** FD · 听力 → 口语

#### 流利度分数算法

每次计分尝试（Step 3、Step 4、Step 4R、MFI、Part B）：

```
A = 准确率:   1.0 一次通过 · 0.5 提示/自我纠正后通过 · 0 失败
v = 实测速度（wpm）
S = clamp( (v − v_floor) / (v_ceil − v_floor),  0, 1 )
attempt = A × (60 + 40 × S)
// 失败 → 0 · 低于 v_floor → 只拿准确率保底 60（不算流利，仍是 LRL） · 达到 v_ceil → 100
```

`v_floor` / `v_ceil` 是按模态设定的速度标尺端点（阅读 150 → 300 wpm，写作打字 25 → 60 wpm；见「目标锚定的流利度」）；不限时的打字任务由延迟换算 v（参考：Step 2/3 打字 = 350ms × 语块长度）。每次计分尝试的延迟和换算出的 v 记录在 `events.detail`（JSON）中。

单个 KP 的更新 —— 在衰减后的先验上做指数移动平均，**只更新本次练习的方向**：

```
R_服务 = max(L_a, 0.8)        // SCORE_R_FLOOR：计分问「间隔后长时痕迹还剩多少」——
                              // 看 L 不看 C×L（缓存冷是设计服务点，不是调度迟到）；
                              // L < 0.8 按 0.8 计，排队过久不罚学习者
F_a ← (1 − α) · F_a · R_服务  +  α · attempt,   α = 0.4
```

一个衰减模型同时服务队列和分数：调度问的是「R 低到值得练了吗？」，计分问的是「间隔之后 F 还剩多少？」。

**P⊃R 迁移（单向、只搬知识）。** 产出方向的计分通过（Step 3 / Step 4）证明了更难的方向，因此同侧面、同义项的接受性知识随之确认：

```
F_R ← max(F_R,  A × 60)        // 干净通过托底 60，hint 通过托底 30
```

60 正是 attempt 公式里「只计准确率」的那条线：*知识已确认，读速未认证*。托底永不拉低 F_R，不碰 H_time_R 和 `last_ts_r`；且 60 < 75，KP 不可能只靠迁移混进集成池——读速必须靠真实的 Step 4R / MFI 通过挣得。反向不迁移（认出绝不等于会用），产出失败也不迁移（写不出 ≠ 认不出）。没有阅读材料的 KP 不做这个区分：每次 P 更新时 F_R 直接镜像 F_P。

稳定度更新按方向各自进行：成功拉长该方向的 H_time（×2——从 1 小时播种，经 1天 → 3天 → 7天 增长），失败缩短它（÷2，下限 1 小时）。H_tick 保持很短（约 4–5 个任务）且双向共享——它唯一的职责是缓存的干扰通道。

聚合：

```
目标流利度  = Σ(wᵢ · min(F_R,F_P)ᵢ) / Σwᵢ,   wᵢ = 1 + log(1 + freqᵢ)   // headline；仪表盘
              另报 R/P 拆分（ΣwᵢF_R / ΣwᵢF_P）作为展示指标
目标达成度  = 双轴均达个人目标（F_R ≥ target_in 且 F_P ≥ target_out）的 KP 的词频加权占比
用户水平    = vocab_estimate（广度，来自词汇量测量）
              × 活跃 KP 的平均 min 流利度（深度）
              → 归一化到 0–100 → 经 levelOf() 映射到 CEFR/IELTS 档位
```

分数语义：**F ≥ target** = 达成个人终点（两个方向都达成且保持力足够 → 毕业），**50–80** = 费力但可靠，**< 50** = 仅停留在再认层面。

Schema 要点：`words` 表持有 `fluency`（F_P）、`fluency_r`（F_R）、`target_in`、`target_out`、`stability_tick`、`stability_time`（H_time_P）、`stability_time_r`（H_time_R）、`last_tick`、`last_ts`（P 锚点）、`last_ts_r`（R 锚点）、`integrated`、`graduated`、`profile`（Nation 侧面清单位掩码）；`goals` 表 `target TEXT` 列存 JSON 目标画像；按用户、按模态的速度游标存在 `meta` 表（`v_cursor_reading`、`v_cursor_writing`）；延迟和准确率评级记录在 `events.detail`。

#### 目标锚定的流利度与毕业规则

F 不是一个抽象分数——它锚定在每个目标声明的、可测量的表现指标上。

**1. 目标画像（target profile）。** 每个目标用可测量的术语声明终态：

```
雅思 7.0 目标：  { vocab_size: 7200, reading_wpm: 200, writing_wpm: 30 }
读书目标：       { reading_wpm: 200, writing_wpm: 25 }
```

拆解方式：`vocab_size` 决定哪些 KP 进入队列；wpm 目标决定每个词的**个人流利度终点**（下文）和每个限时任务的 `T_budget`（`T_budget = 材料长度 / v_cursor`，游标朝目标速度棘轮）。

**2. 每词的个人终点（target_in / target_out）。** 目标速度翻译成每词目标熟练度——目标速度在标尺上的位置映射到 80–95 区间，再按词频向上调制：

```
阅读位置 = clamp((目标reading_wpm − 150) / (300 − 150), 0, 1)   // 150 = 保底理解的最低流利速度
写作位置 = clamp((目标writing_wpm − 25) / (60 − 25), 0, 1)      // 打字标尺；手写标尺 15 → 30 留作模态开关

base_in  = 80 + 15 × 阅读位置      // 150 wpm（流利下限）→ 80 分；300 wpm（母语上限）→ 95 分
base_out = 80 + 15 × 写作位置      // 25 wpm（二语流利下限）→ 80 分；60 wpm（母语平均上限）→ 95 分

target_in  = min(100, base_in  × freqFactor)    // freqFactor = 1 + 0.1 × min(1, ln(1+freq)/ln 101)
target_out = min(100, base_out × freqFactor)    // ∈ [1.0, 1.1]，只向上调制——流利下限不被任何因素
                                                // 稀释；freq ≥ 100 封顶；无词频信息取 1.0
```

入库时物化到 `words.target_in` / `target_out`；目标速度修改时对该目标下所有词批量重算。直觉：读 300 wpm 的目标下，高频词必须接近自动化（target ≈ 95+），低频词也至少是流利线（80）——高频词在阅读中密度高，对速度的拖累大，所以词频只把目标往上推。

**3. F 的含义 = 「个人终点的达成比例」。** gap = (target − F)⁺ / target 使得「离终点还有多远」跨词可比：target 90 的词从 45 爬起是 gap 0.5，target 80 的词从 40 爬起也是 0.5。已达标的轴转入维护：gap 取 MAINT_GAP（0.05），以低优先级留在队列里接受复习，直到 H_time 满 30 天保持力验证通过才归零退场——**毕业语义进了优先级公式**（若达标即归零，H 会被冻在低位，GRADUATED 永远无法达成）。

**4. 自适应速度游标——压力随目标动态调整。** 每个模态一个按用户维护的游标，朝目标速度棘轮式推进：

```
T_budget = 材料长度 / v_cursor                    // 任务中施加的压力
v_cursor ← min(目标速度, v_cursor × 1.05)          // 以游标速度干净通过
v_cursor ← max(v_floor,  v_cursor × 0.90)         // 准确率失败
种子值：v_floor
```

两个速度，两种职责：**游标设定压力**（收缩的时间预算），**实测的 v 在绝对标尺（v_floor → v_ceil）上经 S 计分**。游标 = 训练轮；标尺 = 尺子。4/3/2 技术就是它的手工祖先——同一材料、预算递减——游标只是把它自动化了。

**5. 毕业——停止派练习。** 一个 KP 同时满足以下条件就永久离开队列（P = 0）：

```
GRADUATED ⟺ F_P ≥ target_out  且  F_R ≥ target_in      （双轴都达成个人终点）
          且 H_time_P ≥ 30 天 且 H_time_R ≥ 30 天        （双向都扛住了长时遗忘）
```

对比旧的三轴毕业（F ≥ 80 一刀切 + 末次全速 + H ≥ 30d）：终点从固定 80 改为个人 target，「全速通过」条件被 target 蕴含（F 由含速度分的 attempt 喂大，F ≥ target 本身就意味着速度达标）。

**6. 实测速度校验。** 限时的 MFI/FD 任务同时充当地面真值：阅读 wpm = 篇章词数 / 用时（仅当理解自评通过时有效），写作 wpm = 产出词数 / 写作时长。把每个 KP 的实测 wpm 与 F 的预测值对照画线，用真实数据校准 α、速度标尺和 `60 + 40·S` 公式。

**7. 掌握剖面——「完全学会」的定义。** 按 Nation 的知识剖面框架，认识一个词不是一次考试，而是一张侧面清单，每个侧面都要**独立地双向验证——接受性（R）和产出性（P）**：认出绝不等于会用。按读写范围裁剪后（去掉口语形式侧面）：

| Nation 侧面 | R 检查 | P 检查 | 覆盖任务 |
|---|---|---|---|
| 形式·书写 | 看到能认出 | 能正确拼写 | 阅读接触 / Step 1+2 盲打 |
| 形式·词构 | 认出词干词缀 | 产出正确词形变化 | 缺口 → 词形变化任务（规划中） |
| 意义·形义联结 | 见形忆义 | 由义产形 | MFI 理解任务 / Step 3 |
| 意义·概念所指 | 知道多义项范围 | 用于正确所指 | scene / substitute（部分） |
| 意义·联想 | 知道相关词 | 产出联想词 | substitute（部分） |
| 使用·语法功能 | 接受正确句法模式 | 用在正确模式中 | Step 4 造句 |
| 使用·搭配 | 知道共现词 | 带搭配地产出 | slots / Step 4 / Part B |
| 使用·语域限制 | 知道何时得体 | 得体地使用 | 缺口 → `freq` 只是弱先验（规划中） |

> **P ⇒ R 推导规则。** 某侧面的 P 通过 ⇒ 该侧面的 R 检查记为通过（同侧面、同义项——在该粒度上产出以再认为前提）。R 通过永远不推 P。同一种不对称在分数层表现为流利度算法里的单向 F_R 托底：认证层是二值的，估计层是渐变的，两者都是单向的。



#### 间隔记忆（space memorize）

有了分数驱动队列，间隔不再是一组门禁——它就是优先级函数的形状。

**1. 微间隔（缓存冲刷），涌现式。** 刚练完时 C ≈ 1 → R ≈ 1 → 闸门关闭，KP 沉到队底。之后缓存走双通道冷却：每个穿插任务推进 tick（干扰通道，H_tick ≈ 4–5 个任务），纯粹流逝的时间同样在冲（时间通道，H_cache ≈ 20 分钟）——min 取谁冲得狠算谁。练完去吃饭三小时、一个任务没做，回来缓存也是凉的。每次提取都来自长时记忆——不是门禁强制的，而是新鲜的 KP 根本不值得服务。

**2. 宏间隔（SRS），同一条曲线。** `R_time` 按**该方向自己的**半衰期 H_time 衰减，该方向每次成功使其拉长（1小时 → 1天 → 3天 → 7天，每次通过 ×2），失败使其缩短（÷2，下限 1 小时）。KP 恰好在它自己的衰减曲线说该复习时成熟——不需要独立的阶梯表，也没有逐级到期日。

**3. 时间边界，不存在。** 旧设计要在练习段落结束时做门禁折算和 tick 特判；双通道缓存模型什么都不用做——隔夜只是 Δt 很大的普通情形，缓存的时间通道和长时遗忘一起免费完成衰减，下一次优先级扫描自然把成熟的一切浮上来。系统不记录、也不需要知道用户的练习节奏。

**4. 调度 = 一次优先级扫描**（见领域模型 §5）：

```
Part B 批次（双轴 ≥ 75 未整合 ≥ 5 个） >  P 最大的成熟三元组（R_a ≤ 0.9 且 C ≤ 0.5 双闸门） >  新词插空引入（激活目标，词频序） >  EMPTY
```

**5. 严重逾期的路由。** L 跌穿 RELEARN_R（0.2）的 KP 已不在最优服务窗口内——提取大概率失败，测它只能收获一次「失败」记录。这类词（以 P 轴的 L 为准，理由见领域模型 §5）绕过竞争，直接路由到重编码任务（Step 1+2 式重新引入），承认它已死、重新来过，比重测一次再失败更诚实也更便宜。

**0.8 目标落在校准里。** 一切自适应主张都可归结为一条：在 KP 的 R 降到约 0.8 时服务它——「合意困难（desirable difficulty）」点：回忆费力但仍能成功。成熟阈值（0.9）、H 种子值、×2/÷2 的稳定度更新、URGENCY_GAIN、H_cache、NEW_WORD_BYPASS 都是初始猜测；等 `events` 数据积累起来后，拟合「通过率-R」曲线，把参数调到复习时实测通过率落在 80% 附近。

#### 文献锚点

- **合意困难 / 新失用理论**（Bjork & Bjork）：练习收益在提取强度低但仍可成功时最大——服务窗口的理论基础。
- **半衰期回归**（Settles & Meeder 2016，Duolingo）：p_recall = 2^(−Δt/h) 的指数衰减模型与逐词半衰期回归——我们的 R 公式同构。
- **间隔重复最优控制**（Tabibian et al. 2019, PNAS）：最优复习时刻由回忆概率阈值刻画——过早浪费、过晚失败率飙升，支持「窗口」而非「越忘越好」。
- **FSRS / Anki 实践**：期望保持率默认 0.90（与 RIPE_R 吻合）。
- **Nation 四股线**：MFI / MFO / LRL / FD 四条线的覆盖是任务库设计的依据；时间配比不由调度配额强制，由双轴缺口的需求竞争涌现。
