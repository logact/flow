# 词汇学习调度算法

> 本文是项目核心算法的权威规范。任务、调度、计分、目标和材料准备均以本文为准。本文描述已确认的产品规则，不表示业务代码已经完成实现对齐。
>
> 本次修订：用按轴独立的 `due_at_R/P` 和每日训练容量调度；导入时按用户词汇量与单词词频排名估计 R/P 初分，分数直接决定首题；各轴实测达标后独立按 1、3、7、30 天的相邻间隔复习，两轴各自完成最后一次后词毕业。现有实现和测试尚未据此对齐。

## 第一层：整体决策

每次调度分三步：

1. 按目标轴 `due_at_a`、轴级毕业状态、当天剩余容量和共享冷却选择词 `w` 与轴 `a`。
2. 学习或降级补练按该轴当前分数 `F_a` 确定档位；达标后的定期复习固定为目标轴 FLUENCY。
3. 获取所选档位的合格材料；材料不可用时记录原因并继续比较其他候选。

学习与降级补练中，同一轴、同一分数对应同一任务档位。某轴达标且有有效 FLUENCY 通过后，该轴即可独立进入定期复习，每次固定为该轴一题 FLUENCY。材料不足不能降低档位。R/P 是能力方向，不互相代替，也不互相加分；唯一的连接任务按第二层规定同时初始化两轴。

- `R`：理解方向。
- `P`：产出方向。
- `F_a`：当前训练分数，范围 `0–100`，可以升降；不再表示历史最高成绩。
- `due_at_R / due_at_P`：各轴已排定的下次学习或复习日期；未完成该轴学习时为引入当天（失败补练时为失败当天），定期复习各自按相邻间隔排定。
- `tick` 与词级上次完成锚点：两轴共享的短时冷却。
- `target_a`：用户设置的该轴分数目标。

决策顺序：逾期或今日到期的待毕业轴复习 → 逾期或今日到期的未完成轴学习 → 在容量允许时引入新词 → 等待冷却或今日完成。各组按对应轴的 `due_at_a` 从早到晚，同一时刻按词 ID、R 再 P 稳定排序。已毕业轴 `due_at_a = ∞`，不参与派题；两轴均毕业后词毕业。

取消 `INTEGRATE` 及其批次优先分支，取消先验 `q` 和首次诊断分支。旧 `verified_a`、`speed_verified_a`、`integrated_a`、`axis_done_a` 不参与派发或计分；本版重新定义显式毕业状态，不能直接沿用旧字段语义。失败讲解属于当前反馈，不生成独立计分任务；失败后的补练按新分数正常调度。

## 第二层：任务与分数

### 1. 分数决定学习档位

下表的分数只指当前目标轴，不能用 `min(F_R,F_P)` 替代。仅两轴初分均为 0 的词先做一次词级连接，确认后同时令 `F_R := 5`、`F_P := 5`，计一次有效任务和一次 tick。至少一轴有估计初分的词直接按各轴分数选择首题，0 分轴从 choice 开始；估计分不代表已通过 FLUENCY。

| 当前轴分数 | 类型与档位 | R：理解 | P：产出 |
|---|---|---|---|
| 两轴初分均为 0 且连接未完成 | 连接 / ENCODE | 展示并确认目标词义、形式与例句，一次同时初始化 R/P | 同左 |
| 已引入，`0 ≤ F < 20` | RETRIEVE / choice | 看原词选择正确意思 | 看意思选择正确原词 |
| `20 ≤ F < 40` | RETRIEVE / cued | 在提示下写出意思 | 在字母等提示下写出原词 |
| `40 ≤ F < 60` | RETRIEVE / free | 看原词直接给出意思 | 看意思直接写出原词 |
| `60 ≤ F ≤ 100` | FLUENCY | 连续阅读理解与速度 | 连贯表达质量与速度 |

P 的无提示提取仍提供意思或表达意图，但不提供选项、答案字母等线索。有提示任务的支架是该档正式要求，不应因使用规定提示而判无效。

### 2. ENCODE 与 RETRIEVE 计分

按结果直接设置分数，不采用固定小额加减，也不以个人目标截断本次表现分。

| 当前任务 | 成功后的分数 | 失败后的分数 |
|---|---:|---:|
| 连接 / ENCODE | 确认学完后两轴各至少为 `5` | 未完成时两轴不变 |
| 选择 | `20` | `5` |
| 有提示提取 | `40` | `5` |
| 无提示提取 | `60` | `20` |

连接任务不设额外测验；后面的 RETRIEVE 检验掌握情况。选择失败后可展示讲解，但不回到连接任务。已按估计初分进入练习的词不再补做连接；其 0 分轴按 choice 练习。

双轴从 0 分且目标为 80 时，连续成功路径为：一次连接、R/P 各三次 RETRIEVE、R/P 各一次 FLUENCY，共 9 个有效任务。估计初分可跳过已跨过的档位，首日预算按各轴实际起点计算，不能一律计 9 题。每次完成后返回调度器，目标是在引入当天走完；共享冷却仍适用。答错、未达目标或更高个人目标会增加任务数。

结果判定：

- 选择题匹配事先固定的正确选项。
- R 释义作答由 AI 对照本题目标释义判定，接受意思正确的同义表达。
- P 原词作答做规范化匹配，忽略大小写及首尾空格；只接受题目预先允许的词形变化。
- 答案、目标词义和判定要求在派发前确定。反馈后修改答案不能覆盖首次作答结果。
- 材料有问题、AI 无法判定或服务失败不是用户答错，不更新分数。

### 3. R FLUENCY

#### 材料

- 短文固定为 100 个英文词。
- 除目标词外，生成材料应结合 P3.1 按词族频段估计的认识概率选择非目标词；该概率档案不转换为 A1/B1/C1 等 CEFR 等级。若另行配置内容难度约束，应与词汇概率档案分开保存。
- 目标词自然出现至少 5 次，保存实际出现次数。
- 本次有一个明确的计分目标词和 R 轴；文中其他词不自动获得分数。
- 提供两道题：目标词在文中的含义、整段核心意思或关系。避免用零碎细节记忆代替理解。
- 题目、正确答案和原文依据在派发前固定。

该任务测得的是目标词重复出现的材料中的阅读表现，不应宣称是所有陌生材料上的通用阅读速度。

#### 阅读与回看

1. 显示短文时开始阅读计时，不展示目标词释义。
2. 用户点击“读完”，暂停阅读计时并隐藏原文，显示理解题。
3. 用户可以返回原文；回看期间隐藏题目，继续累计阅读时间，不提前显示答案。
4. 结束回看后继续答题；提交后判定结果。

```text
reading_seconds = initial_reading_seconds + sum(rereading_seconds)
reading_wpm = text_word_count × 60 / reading_seconds
```

答题时间不计入阅读速度。计时失效或阅读中断，本次视为无效作答，不以不完整时间计分。

#### 分数回写

先检查材料和计时有效，再检查理解结果，最后计算速度分。

| 目标词含义题 | 整段理解题 | 处理 |
|---|---|---|
| 正确 | 正确，且 `reading_wpm ≥ 150` | 按速度直接更新 R 分数 |
| 正确 | 正确，但 `reading_wpm < 150` | 设为 `40` |
| 正确 | 错误 | 分数不变，记录整段理解未通过 |
| 错误 | 正确或错误 | 设为 `40` |

```text
F_R_new = min(100, 60 + (reading_wpm − 150) / 3.75)
// 仅在两题都正确、计时有效且 reading_wpm ≥ 150 时使用
```

150 / 225 / 300 wpm 分别对应 60 / 80 / 100 分。200 wpm 对应约 73.3 分，不论旧分为 60 还是 80，都直接写入本次表现分。存储和比较使用未舍入值，展示精度不改变调度结果。

不使用速度比加减分、正确率乘速度、平滑更新或历史最高分保底。进入 60 分不要求此前通过 150 wpm 测验；60 分也可能来自无提示 RETRIEVE，通过记录区分分数来源。

### 4. P FLUENCY

#### 材料与作答

- 用中文描述一组场景，要求以目标词对应的意思为核心复述题目内容。
- 不展示英文目标词，不提供可照抄的英文答案。
- 用户主动点击开始后计时，提交时结束；包含构思、输入、停顿和修改。
- 最终表达至少 30 个英文词，不能靠无意义重复凑字数。
- 必须出现并正确使用目标词，允许符合语境的词形变化。
- 一次只给明确的目标词和 P 轴计分。

题目应能自然引出指定目标表达。其他表达即使语义合理，也不满足本次“使用目标词”的要求；反馈应区分未满足任务要求与语言本身错误。

```text
writing_wpm = final_valid_word_count × 60 / writing_seconds
```

删除的内容不计入最终词数。少于 30 词时提示继续完成，不形成有效速度成绩。

#### AI 判定与分数

AI 分别返回目标表达结果、整体复述结果及原文依据：

- 目标表达：是否实际使用目标词或允许词形，含义、搭配和语法作用是否成立。
- 整体表达：是否复述中文题目要求的内容，语义连贯清楚；允许不影响理解且不涉及目标用法的小错误。

| 目标表达 | 整体复述 | 处理 |
|---|---|---|
| 通过 | 通过，且 `writing_wpm ≥ 25` | 按速度直接更新 P 分数 |
| 通过 | 通过，但 `writing_wpm < 25` | 设为 `40` |
| 通过 | 未通过 | 分数不变，记录整体表达未通过 |
| 未使用或使用错误 | 通过或未通过 | 设为 `40` |

```text
F_P_new = min(100, 60 + (writing_wpm − 25) × 40 / 35)
// 仅在两项通过、计时有效且 writing_wpm ≥ 25 时使用
```

25 / 42.5 / 60 wpm 分别对应 60 / 80 / 100 分，直接写入本次表现，可以升降。

#### 无效作答

- 从点击开始至提交不超过 5 秒，本次无效，不改分。这个规则只校验最短用时，不能识别所有粘贴行为。
- 中断视为没有答题，不改分；需重新开始才能产生有效计时。
- AI 无法判定、判分服务失败或材料错误时不扣分，保留作答供重试判分。
- 无效性检查先于质量扣分和速度计分，不能先按目标词缺失扣分再发现本次计时无效。

## 第三层：目标、状态与排期

### 1. 个人目标与导入

用户分别设置 R/P 分数目标 `target_R / target_P`，合法范围为 `60–100`，原型默认均为 `80`。目标不由速度或词频推导；修改目标不改已有分数，但要重新检查学习完成和毕业资格，必要时撤销未执行的旧排期并重排。

```text
score_met_a = F_a ≥ target_a
learning_complete_a = score_met_a 且该轴有达到目标的有效 FLUENCY 通过记录
learning_complete = learning_complete_R 且 learning_complete_P
```

导入时用用户估计词汇量 `V > 0` 和与其口径一致的单词词频排名 `rank` 计算初分；排名越小表示词越常见。原型规则如下，可由实际答题数据校准：

| 条件 | 初始 `F_R` | 初始 `F_P` | 连续成功的最少首日任务数（目标 80） |
|---|---:|---:|---:|
| `rank ≤ 0.5V` | 60 | 40 | 3 |
| `0.5V < rank ≤ V` | 40 | 20 | 5 |
| `V < rank ≤ 1.5V` | 20 | 5 | 7 |
| `rank > 1.5V`，或 `V/rank` 缺失、来源不可比 | 0 | 0 | 9 |

`rank` 必须是确定来源、可与 `V` 比较的词汇排名；原始词频值不能直接当排名。估计初分不是实测证据，不能设置 `fluency_pass_a`、`learning_complete_a` 或毕业状态。只有两轴均为 0 时先做一次连接；其他词从分数对应的题型开始。用户词汇量同时可用于材料难度匹配，但不能另行覆盖此分档；词频来源不同不能静默混排。若用户重新估算词汇量，已开始练习的词不自动重置实测分数或排期。

### 2. 必要状态

```text
F_R, F_P                    // 当前轴分数
introduced                  // 是否已进入练习：完成连接，或接受非零估计初分并准入
fluency_pass_R/P            // 各轴是否有达到目标的有效 FLUENCY 通过记录；分数低于目标时清除
learning_complete_R/P       // 各轴已达目标且具备 FLUENCY 证据
learning_complete           // 两轴学习均完成的汇总状态，不阻塞单轴开始复习
review_level_R/P            // 各轴下次待做的复习间隔：1、3、7、30 天
graduated_R/P               // 各轴通过自己的 30 天间隔复习
graduated                   // 两轴均毕业后的词级终态
due_at_R/P                  // 各轴下次排期；该轴毕业时为 ∞
last_ts_any, last_tick_any  // R/P 共用的上次有效任务完成锚
tick                        // 全局有效任务计数
target_R, target_P
```

历史分数、半衰期和遗忘率不参与本版派题；不以时间推测自动降低 F。毕业状态由本版复习流程生成，不能从旧 `graduated` 字段或历史最高分直接推导。一个词的两轴只共用冷却；分数、学习完成、复习级别和 `due_at_a` 均按轴独立保存。

### 3. 当天学习与共享冷却

未准入词属于新词候选；准入时按估计初分决定是否需要连接。准入后，各轴在自己的 `learning_complete_a` 之前，`due_at_a` 为准入当天的本地日期；若该轴复习失败后降分，则为失败当天。每次有效学习任务后仍在该轴的当天学习队列，直到该轴完成目标、当天容量或时间不足。跨过排定日期仍未完成时，该轴成为逾期学习轴；不能悄悄重设为下一天的新词。一个轴完成学习即可进入自己的定期复习，另一轴继续学习。

```text
cooldown_ready(w) =
  没有词级完成锚
  或 tick − last_tick_any(w) ≥ 7
  或 now − last_ts_any(w) ≥ 20 分钟
```

七个任务指该词上次完成后发生的七个其他有效任务，R/P 一起计数。跳过、中断、退出、无效作答不推进 tick 或冷却锚。`due_at_a` 已到但冷却未结束时返回等待及最早可用时间；不能把“暂时不能派”报告成“今天已完成”。同一轴学习中的下一题由该轴分数决定，该轴达标且有有效 FLUENCY 后即进入自己的定期复习。

### 4. 达标后的定期复习与毕业

从各轴自己的 `learning_complete_a` 有效结算日期开始，该轴成功复习后的相邻间隔依次为 **1、3、7、30 个本地日**；每次到期只签发该轴一题目标词 FLUENCY。该轴通过即可独立前进到下一级，不等待另一轴。通过自己的 30 天间隔复习后设 `graduated_a = true`、`due_at_a = ∞`；两轴均毕业才设 `graduated = true`，停止该词调度。每轴连续通过的最短复习日期为该轴首次达标后的第 1、4、11、41 天；两轴起点可以不同，同词练习始终遵守共享冷却。

复习通过要求目标项、整体项、该轴速度要求均通过，结果有效，且新分数仍达到个人目标；不能只因分数碰巧保持不变就判为通过。该轴复习失败时照第二层规则更新实际分数，并将该轴下次复习级别退回一级：1→1、3→1、7→3、30→7。若该轴低于目标，清除该轴的 `fluency_pass`，撤出该轴定期复习队列，`due_at_a` 变为失败当天，按当前分数补练；该轴重新通过达到目标的 FLUENCY 后，从退回的间隔重新排期，不等待另一轴。未降分但未通过的有效 FLUENCY 不清除该轴原有达标证据，也不前进间隔，按退回的间隔重排。无效或不确定结果不改该轴分数、复习级别和 `due_at_a`，保留作答供重试或重新开始。另一轴的分数、复习级别和排期不因本轴结算而改变。

`due_at_a` 是该轴排定的复习日期，不是记忆概率或到期自动扣分。所有日间隔按用户本地日历日期计算；完整时刻、时区和夏令时转换须一致保存，避免同一任务跨日重复派发。

## 第四层：容量约束与调度器

设 `S` 为激活目标内的词（strict 模式），或全词库（默认模式）。一次实例只练一个词和一个轴；唯一连接任务同时初始化两轴。材料可用性只能决定能否签发当前档位，不能静默降档。

### 1. 每日容量与 41 天视图

用户的每日可完成任务数为 `capacity(d)`，原型模拟使用每天 100 次；这是容量输入，不是用户必定完成 100 次的保证。有效完成的任务计入当日实际消耗。每次练习结算后，重算其影响下**今天至第 41 天（含第 41 天）**各本地日的已确定到期任务、条件性未来任务和剩余容量；新词准入时也执行同一检查。两轴一次复习各占一个任务名额。

```text
remaining(d) = capacity(d) − 已完成(d) − 未完成的已确定排期(d) − 未完成的条件预约(d)
```

各轴当前的下一次 `due_at_a` 是已确定排期；该轴下一步通过后才能发生的后续复习属于条件预约，必须与确定排期分列，不能当作已经发生的作答。一次新词按估计初分对应的最少首日任务数（3/5/7/9）做容量检验，并为 R/P 分别按各自预计首次达标日期后的第 1、4、11、41 天各预留一题；若两轴达标日期不同，预约也落在不同日期。答错、目标高于 80 或实际表现不足时，必须用实际剩余任务重新计算，不能仍按最短成功路径宣称足额。

新词只有在当天任务名额、材料及剩余时间均足以遵守共享冷却时才准入；不能仅凭 `9 ≤ remaining(today)` 推断必能当天走完。每次真实结果到来后，只重排受影响轴不再成立的条件预约，并重算逐日总容量；另一轴已确定的 `due_at_a` 保持不变。若任一日已经超容量，停止准入新词并明确报告短缺；不能通过把已确定 `due_at_a` 静默后移来伪造容量充足。未来 41 天视图是滚动估计，用户未完成、额外失败或材料故障可能使实际需求超出估计，必须显示逾期并优先处理。

### 2. 唯一派题顺序

对可派发且已满足共享冷却的候选按以下顺序选取：

1. 已完成该轴学习但尚未毕业的轴中，`due_at_a` 为今天或更早的复习；最早 `due_at_a` 优先。
2. 未完成该轴学习的轴中，`due_at_a` 为今天或更早的任务；最早 `due_at_a` 优先。同一词可以同时提供一个复习轴和一个学习轴候选。
3. 当天及 41 天容量检查通过时引入新词；新词按来源可比较的词频、目标缺口、词 ID 和同词 R 优先稳定排序。
4. 没有可派发旧任务且不能准入新词时返回今天完成、冷却等待、材料不可用或容量不足的具体原因。

已毕业轴 `due_at_a = ∞` 不参加竞争。对同一 `due_at_a` 使用词 ID 升序、同词 R 先于 P 的稳定顺序。到期但因冷却未就绪的高优先级轴暂不阻塞其他可派候选；冷却结束时重新比较。到期轴未完成时保持原 `due_at_a`，跨日自动成为逾期，不能为了引入新词顺延。只有用户显式改变目标、范围或其他已排期前提时，才按新状态重算相应排期并记录原因。

### 3. 材料不可用与空队列

对选定候选先找当前档位的合格材料，不足时在有限预算内生成、校验并缓存；仍失败则记录原因并比较下一候选。不得因 FLUENCY 材料失败降成 RETRIEVE，也不得把材料不可用算作用户答错、完成或毕业。

无任务时区分：今天任务确已完成、新词容量不足、仍在共享冷却、材料准备或失败、范围无词。返回可确定的下一次冷却结束时间或最早 `due_at_a`；无法确定的材料恢复时间为 null。用户当日实际训练容量小于已到期任务数时，记录未完成和逾期数量，次日优先处理，不声称按期保证已满足。

## 第五层：材料准备与 AI 保底

### 1. 导入时准备

导入后启动后台准备，优先保证当前分数对应的档位可练，再准备下一档：

- 确认目标词义与 gloss；两轴初分均为 0 时准备 ENCODE，否则从实际首题档位准备材料。
- 接近或达到 60 时准备 R 短文及理解题、P 中文场景与判定要求。
- 已有材料使用后持续补充，保存使用记录，避免依靠背答案通过。
- 不要求导入时穷尽生成所有未来材料；P3.1 词汇概率档案、单独配置的内容难度约束、主题和词义变化时重新匹配。

### 2. 释义与校验

缺 gloss 时，用户手动填写或确认 AI 建议后保存。未确认的 AI 建议不是正式释义，不用于生成正式判分依据。修改 gloss 后，使旧词义对应材料失效并重新生成。

材料状态至少区分准备中、可用和生成失败。生成后检查目标词义一致、答案明确、干扰项合理、提示符合档位要求，以及 FLUENCY 的长度、难度和目标词使用要求。P 场景不得泄露英文目标词。生成成功不等同于校验通过。

### 3. 练习时保底

已有有效材料 → AI 生成同档材料 → 校验 → 缓存并派发。生成失败或校验失败可有限重试；仍失败则记录原因并尝试其他候选，不改变分数。

作答后的判分失败与材料生成失败分开处理：保留用户作答，允许重试判分，不要求重新表达，也不提前写入失败成绩。

## 第六层：实例、回写与记录

### 1. 任务实例

每个实例在派发时固定：

```text
instance_id, definition_id, word_id,
axis: r | p | both,  // both 仅用于唯一的词级连接任务
type: ENCODE | RETRIEVE | FLUENCY,
stage: encode | choice | cued | free | fluency,
purpose: introduce | review | recover,
score_before, material_id, material_version,
target_sense, payload, grading_requirements, timing_protocol
```

`purpose` 只解释为什么此刻练，不改变类型、档位或评分。除已确认的词级连接任务外，一次总体结果不能自动更新两轴或文中所有词。定期复习实例仍分别冻结 R/P 轴、材料、答案和计时要求。

### 2. 状态回写

有效连接完成或有效作答只结算一次：

1. 连接任务同时把两轴低于 5 的分数设为 5；其他有效作答只按任务结果更新目标轴 F。
2. 双轴 0 分词在连接有效完成时设置 `introduced`；非零估计初分词在准入时已设置，结算不重复计连接。记录目标轴达到目标的有效 FLUENCY 通过证据；检查该轴学习完成、复习级别与毕业资格，再汇总词级毕业状态。
3. 重新计算目标轴 `due_at_a`、今天至第 41 天的总容量及该轴仍成立的条件预约；不能在答错后保留该轴全通过路径的旧预约，也不能改写另一轴已确定排期。
4. 更新共享 `last_ts_any`、`last_tick_any = tick + 1`，全局 tick 增加一次。
5. 原子保存分数、排期、容量占用和事件；重复请求返回已处理结果，不重复加 tick 或占用名额。

分数保持不变的有效作答仍需记录，不能与无效作答混淆；它是否推进该轴复习级别由复习通过条件决定。反馈讲解不生成另一笔计分或额外 tick。未完成连接、无效计时、中断、材料错误及服务失败不改变 F、复习级别、`due_at_a`、冷却锚或 tick。

### 3. 中断、跳过与退出

FLUENCY 中断后，本次视为未作答：不改分、不重排 `due_at_a`、不更新冷却锚、不增加 tick；保存中断原因。重新开始时重新计时，不能拼接中断前后的用时生成成绩。具体中断检测事件仍需明确，不能仅凭长时间没有输入推断用户已离开。

保留显式跳过，不支持延期：

- 跳过将当前实例标记为 skipped，记录一次 `task_skipped`，签发下一任务。
- 不改变 F、复习级别、`due_at_a`、冷却锚或 tick；不额外降低优先级。
- 被跳过的词保留原到期时间，仍最优时可能再次出现。
- 重复跳过请求不重复记事件。
- 退出与跳过分开记录，实例终态互斥；跳过后不再记退出。
- 未提交上滑仍忽略，不解释为跳过。

```text
跳过率 = skipped / (attempts + skipped)
退出率 = exits / (attempts + exits + skipped)
```

展示分子和分母；中断／无效作答不计入有效 attempts。

### 4. 练习历史

记录至少包括：

- 实例、目标词、轴、任务类型、档位、用途、材料及版本、时间。
- 用户答案、每个检查项结果、AI 判定依据和失败／无效原因。
- 文本词数、目标词出现次数、首次阅读与各次回看用时、写作用时、实测 wpm。
- 更新前后分数、目标轴 `due_at_a`、复习级别、轴与词的毕业状态、容量占用及原因。
- completed / skipped / exited / invalid 等结果，及判分重试信息。

缺少测速记录为 null，不沿用上次速度。保存历史用于查看变化，不单独维护历史最高分状态，也不用历史最高分保护当前成绩。

## 参数与待决策事项

### 已采用的产品参数

| 参数 | 当前规则 |
|---|---|
| 任务边界 | 0 / 20 / 40 / 60 / 100 |
| 词级连接完成分 | R/P 各至少 5；只结算一次 |
| R 材料 | 固定 100 个英文词，目标词至少出现 5 次 |
| R 速度标尺 | 150–300 wpm 对应 60–100 分；低于 150 退到 40 |
| P 材料 | 中文场景，至少产出 30 个英文词，必须使用目标词 |
| P 速度标尺 | 25–60 wpm 对应 60–100 分；低于 25 退到 40 |
| P 最短时间 | 不超过 5 秒无效 |
| 冷却 | 7 个其他有效任务或 20 分钟，任一满足；R/P 共用 |
| 新词理想当天任务 | 按词汇量/词频排名初分分别为 3/5/7/9 次；双轴 0 分才需一次连接 |
| 未完成学习词到期 | 引入当天；跨日未完成保持逾期 |
| 达标后复习 | R/P 各自从有效 FLUENCY 达标日起，按相邻成功间隔 1、3、7、30 个本地日独立复习 |
| 毕业 | 各轴通过自己的 30 天间隔复习后 `due_at_a = ∞`；两轴均毕业后词毕业 |
| 容量视图 | 今天至第 41 天，含第 41 天；确定排期与条件预约分列 |
| 个人目标 | R/P 各 60–100，原型默认 80 |
| 每日容量 | 用户输入或历史估计；100 次仅用于示例，不是通用默认值 |

这些是产品参数，不应宣称是研究直接给出的通用能力界线。速度、材料与任务分段需通过实际数据校准。

### 实现前需要明确的边界

1. 每日容量的获取与用户未做满时的重排策略、一天可训练的具体时间窗口、当天连接后剩余时间是否足以完成九次任务的判定。容量不足时不得伪报按期完成。
2. 导入已有初分、个人目标为 60 或高于 80、两轴达标日不同或一轴通过一轴失败时的条件预约预算；实际分数与两轴结果仍按本文规则处理。
3. 如何结合 P3.1 频段认识概率筛选材料、如何使用单独配置的内容难度约束，以及英文词数和目标词词形出现次数的统计口径；不得从概率档案推导 CEFR 等级。阅读材料长度固定为 100 个英文词。
4. 中断的具体检测事件、材料生成数量和重试上限、显示分数精度，以及并发作答的状态冲突处理。

不得以未确定的边界为由静默恢复先验、L/C 急救、低分回退材料或旧毕业字段语义。
